## Verbatim core proposal

> A later REE version need not obsolete an earlier version. Each version can instead define a
> reproducible cognitive preparation: an organism with a deliberately bounded set of capacities.
> The important question becomes not simply whether V4 is more capable than V3, but what new class
> of phenomenon becomes possible when a particular capacity enters the organism.

The thought reframes REE's version ladder (V3 causal/solitary organism -> V4 enduring individual ->
V5 social organism -> later language-capable organism) as **capacity-defined experimental
organisms rather than superseded software releases**. It argues a completed V3 stays scientifically
valuable after V4/V5 exist (tractability, reproducibility, causal access), proposes retaining an
**organism library** of variants (naive, canonical reference, sleep-deprived, attribution-impaired,
lesioned, childhood-varied), introduces **bridge organisms / capacity knock-ins** that add one
boundary capacity at a time for causal isolation between named generations, states that higher
capacities create both capability and *confound* (a rule: "use the lowest-capacity preparation that
contains the phenomenon required to answer the question"), sketches version-specific practical
niches and an **ecological passport** per organism, distinguishes **architectural ancestry**
(mechanisms inherited) from **ontogenetic ancestry** (developmental regime actually lived through),
and closes with a welfare-aware replacement principle compatible with a precautionary 3Rs analogue.

## Key formulations (verbatim, load-bearing)

> A later REE version need not obsolete an earlier version.

> The important question becomes not simply whether V4 is more capable than V3, but what new
> class of phenomenon becomes possible when a particular capacity enters the organism.

> Unlike biological experiments, an artificial organism can be checkpointed, rewound, cloned,
> given the same childhood again, exposed to a single altered event, or rerun with one pathway
> lesioned while every other state is preserved.

> These would function like knock-in or mutant strains in model-organism research. They would
> not necessarily become public release numbers. Their purpose would be causal isolation.

> Use the lowest-capacity preparation that contains the phenomenon required to answer the
> question.

> Does a later social mind develop differently depending on the kind of solitary agent it was
> before other minds became cognitively meaningful?

> Use the cognitively least elaborate organism capable of answering the scientific question.

> The most important shift is from software succession to experimental stratification.
