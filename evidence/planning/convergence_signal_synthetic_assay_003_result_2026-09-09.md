## Executive result

Assay 003 **passes all five preregistered criteria**.

The result supports the opposite side of the convergence–divergence proposal in the frozen synthetic world:

> **Structured disagreement becomes useful for information allocation only after the system represents whether the disagreement is reducible, consequential, and generated by genuinely distinct routes.**

Raw disagreement by itself performs badly because it is attracted to unresolved patterns even when the query is pure noise.

### Main comparison

```text
selector               mean regret   optimal-query hit   oracle utility captured
raw uncertainty         0.94250       30.97%              50.73%
raw disagreement        0.94250       30.97%              50.73%
reliability-only VOI    0.13645       72.34%              92.87%
global N_eff VOI        0.01964       90.48%              98.97%
topology-aware VOI      0.00490       96.65%              99.74%
exact oracle            0.00000      100.00%             100.00%
```

Raw uncertainty and raw hard-vote disagreement are deliberately equivalent in this first binary-vote world. Their weakness is therefore not surprising. The meaningful comparison is M4 topology-aware value of information versus M3 global-`N_eff` value of information, because both already receive query reducibility and consequence weight.

```text
absolute gain = 6.17 percentage points
```

The preregistered requirement was >= 3 percentage points.

## C3 — irreducible disagreement is not mistaken for information hunger: PASS

The mandatory trap is a query channel with `q=0.50`: observing it cannot reduce uncertainty about the hidden truth.

Selection rate:

```text
raw disagreement   20.24%
topology-aware      0.005%
```

The very low non-zero rate for the value-of-information selectors occurs only in ties/episodes where available query utilities collapse to zero; it is not evidence that the selector values the noise channel.

This is the critical conceptual result:

> **Disagreement is not information value. Reducible, consequential disagreement can be information value.**

---

## C4 — exact value of information remains the ceiling: PASS

The exact selector has zero regret by construction and no episode violates the oracle ordering.

Again, the proposed REE-relevant mechanism is a bounded approximation problem, not a rival to exact inference.

---

## C5 — the topology gain is not merely consequence weighting: PASS

The reliability-only and global-`N_eff` methods already receive:

- historical query reliability `q`;
- consequence weight `w`;
- evaluator reliability;
- and, for M3, one global dependence scalar.

M4 still improves materially over both.

Therefore the gain in this world specifically comes from retaining **which reporters belong together and which routes remain distinct**, rather than simply remembering that some questions matter more.

## What the three assays now say together

### Assay 001

Five independent reasons and one reason copied five times can look identically unanimous while warranting radically different confidence.

### Assay 002

One global effective-source scalar is insufficient when dependence has internal topology; coarse provenance clusters can recover much of the exact Bayesian answer.

### Assay 003

The same coarse topology can improve scarce information allocation when several unresolved views pull toward the same unknown, but only when combined with reducibility and consequence.

This gives the first experimentally disciplined version of the original conversation:

```text
credible independent convergence
    + low consequential dissent
    -> closure / confidence is potentially warranted

credible structured divergence
    + reducible uncertainty
    + consequential leverage
    -> additional observation / computation may be warranted
```

Neither sign is useful alone.

---

## The largest remaining convenience

Assay 003 deliberately makes one strong simplification:

> **the number of provenance clusters is also the number of distinct downstream views that benefit from resolving the unknown.**

That makes provenance informative about both:

1. evidence independence; and
2. cross-model leverage.

Real REE will not be so tidy.

Two channels can be statistically independent but concern the same downstream consequence. Conversely, two highly correlated systems may still control different consequential functions. Evidence independence and usefulness leverage therefore need to be separated.

This is now the most important next falsifier.

## Next assay

Construct a world in which:

```text
source-dependency topology != downstream-impact topology
```

Examples:

- five independent evidence routes all update one downstream decision;
- one correlated evidence cluster updates several genuinely distinct consequences;
- two independent routes differ in domain competence;
- provenance metadata is partially wrong or missing;
- query reliability must be learned rather than supplied.

The topology-aware policy should only survive if it can separately estimate:

```text
How many independent reasons do I have?
vs
How many distinct consequential models would learning this resolve?
```

That distinction is likely essential before touching REE's real information-hunger machinery.

## Claim posture

Still **no claim minting from the synthetic sequence alone**.

The programme has now earned a stronger working hypothesis, but not a biological or architectural commitment:

> **A bounded system can benefit from maintaining coarse information about the dependency and impact topology of its internal evaluators. Independent convergence can approximate evidential confidence; structured reducible divergence can approximate where information gathering has high cross-model leverage.**

The next assay should try to break the phrase **“dependency and impact topology”** by separating those two quantities.
