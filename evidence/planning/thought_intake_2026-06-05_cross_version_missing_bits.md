## 1. Core idea

Per-version "missing thing" + closure question:
- **V3** -- missing the **cue/wanting -> action authority -> safe gradient-following -> contact
  -> survival-preserving autonomy** bridge. Closure Q: can fired wanting/cue become safe,
  multi-step, contact-producing behaviour? (This is the live 638a/640 question.)
- **V4** -- missing an explicit **object / action / self / other / joint-attention closure map
  with executable gates**. Closure Q: can the organism inhabit a richer object+social world with
  grounded attribution and affordances?
- **V5** -- missing a **grounded communication ecology with convention + repair + grammar-binding
  gates**. Closure Q: can communication become useful enough to stabilise into proto-language?

**The registerable insight: event-arc structure is a hidden cross-version spine.** Action is NOT
a point event; it is an arc: `initiate -> continue -> interrupt -> reorient -> resume ->
complete / fail / abandon`. The same arc appears in V3 (cue fires -> move -> hazard interrupts ->
resume/lose -> contact), V4 (self/other attribution depends on who initiated/caused/interrupted/
resumed/completed), and V5 (grammar's tense/aspect/because/but/unless/done/again/stop/resume).

The event-arc's weakest span -- **interrupt -> reorient -> resume** -- is exactly the gap memory
`project_interrupted_task_resumption_gap` records (REE has world-staleness invalidation but no

Zeigarnik). This intake gives that gap a cross-version home: it is one segment of the ActionEventArc
spine, load-bearing in V3 (hazard-interrupt-then-resume) through V5 (aspect: resumed/abandoned).
