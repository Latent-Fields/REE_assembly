## 1. Verbatim prompt / core proposal

The thought is the third of a three-part 2026-08-12 sequence, explicitly extending
`2026-08-12_responsibility_as_epistemic_hygiene.md` (single-agent self-solicited-evidence
discounting -> INV-012 Leg 4, Q-096) and `2026-08-12_other_agent_provenance_bounded_animistic_prior.md`
(multi-agent evidential discounting -> INV-102, MECH-504), both already ingested. This thought asks
a different question from either predecessor: not "how should evidence generated by another agent be
discounted," but **"how does agency get inferred in the first place, and how does an inferred other's
harm come to matter to REE's own behaviour."**

> **Core hypothesis:** In a world containing other adaptive systems, persistent structured
> prediction error can create pressure for progressively richer causal models. Agency may be
> inferred when hidden-state, goal-like and information-sensitive models of an entity predict its
> behaviour better than passive-world alternatives. When the inferred entity also exhibits
> organised responses to harm or goal frustration, it may cross an operational threshold for
> treatment as a vulnerable goal-directed other. Fast empathy can then be understood as a gated
> transfer by which inferred other-state gains motivational significance while self/other identity
> remains preserved.

The thought proposes a staged pipeline (structured prediction error -> orient/investigate ->
persistent entity representation -> hidden-state hypothesis -> responsiveness -> info-sensitive
responsiveness -> goal-like latent structure -> other-agent model -> bounded recursive ToM), a set of
"required functional boundaries" the pipeline implies, active investigation as causal epistemology
(interventions that discriminate competing causal explanations), an "operational otherhood
threshold" (goal-directedness + harm/threat-responsiveness, uncertainty-preserving about subjective
status), fast empathy specified as a **gated** transfer (explicitly NOT "an undifferentiated scalar
leak from `other_harm` to `self_harm`") requiring at minimum mapping, identity preservation, gain
control, context gating, timescale control, action-selection access, and learning, a list of
biological systems to investigate as gating substrates (not implementation candidates), an
evolutionary framing (ToM as an economical solution to multi-agent causal prediction rather than a
bolted-on module), an ethical bridge to "others exist" / "others matter," and a staged experimental
curriculum with matched non-agentic controls.

## 3. Key formulations (verbatim, load-bearing)

> Agency is therefore potentially an inference earned when an agent-like latent model predicts the
> entity better than passive-world alternatives, rather than a hard-coded perceptual label.

> Every richer level requires an exit condition: if it fails to improve prediction enough to
> justify its complexity, inference should collapse toward the simpler causal model.

> This does **not** prove subjective experience or sentience. The appropriate claim is weaker:
> converging evidence for information-sensitive adaptive behaviour, persistent goal structure, and
> harm-like organisation may become sufficient for REE to cross an operational threshold for
> treating the entity as a vulnerable goal-directed other while preserving uncertainty about its
> subjective status.

> The key claim is that this should not be an undifferentiated scalar leak from `other_harm` to
> `self_harm`.

> An always-open empathy channel could be paralysing in a world containing many suffering agents.
> An excessively closed channel produces indifference. The scientific problem is therefore the
> dynamics of *whose state gets through, when, how strongly, for how long, and into which
> behavioural systems*.

> Recognising another entity as an agent changes both how its actions should be interpreted
> epistemically and how its existence should be treated ethically. These need not be identical
> thresholds. [paraphrased convergence with the immediately-preceding sibling thought, which states
> the same non-collapse point for the epistemic/ethical distinction specifically]
