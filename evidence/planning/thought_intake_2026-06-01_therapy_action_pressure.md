## 2. The novel content: therapy as symbolic-commit conversion

Hypothesis: therapy works partly because **undifferentiated affective action-pressure is converted
into symbolic (verbal) action**, whose prediction mismatch / social witnessing then updates future
trajectory scoring. The success vs failure split is the load-bearing part:

- **Works:** `activation -> naming -> low-risk symbolic commit -> prediction mismatch / social
  witnessing -> update of future arbitration`.
- **Fails (rumination):** `affect -> repeated verbal loop -> NO prediction mismatch -> no new
  candidate ranking -> rumination / perseveration`.

So a therapy-like mechanism requires a formal distinction among **commit TYPES**: symbolic commit /
embodied commit / social-witnessed commit / rumination loop / repair commit / grief commit /
boundary-setting commit. The discriminator between therapeutic update and rumination is whether the
symbolic commit generates a *prediction mismatch* (or social witnessing) that re-ranks candidates --
not the verbalisation itself.

## 4. Candidate claims (therapy bridge only)

- **Candidate MECH (symbolic-commit-updates-arbitration)** -- verbal/symbolic representation of
  affective pressure is a low-risk partial commit; when it produces prediction mismatch or social
  witnessing, it updates future trajectory scoring. *[novel]*
- **Candidate MECH (rumination-as-mismatchless-symbolic-loop)** -- repeated symbolic commits that
  generate no prediction mismatch fail to re-rank candidates -> perseveration. *[novel; ties to
  OCD/depression perseveration]*
- **Candidate ARC (commit-type-taxonomy)** -- distinguish symbolic / embodied / social-witnessed /
  repair / grief / boundary / rumination commits. *[novel; extends MECH-094 tag machinery]*

These are V4-leaning (require symbolic/language + social-witnessing substrate) but the
rumination-vs-update discriminator may have a V3-tractable proxy via residue + prediction-mismatch
instrumentation. Gate behind the language/social substrate per the biology-first rule.
