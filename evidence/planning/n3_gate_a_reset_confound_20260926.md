## 3. Verdict rule (fixed before any registered seed)

**Canary (both arms' own sanity check, checked first):** the OFF arm's (i) all-states DISC_0.5 and FULL per-seed Spearman diffs (REAL minus SHUF) must reproduce `n3_e3_aggregation_probe_20260925.md`'s committed table (9608f3117a) within 1e-6 absolute (deterministic `torch.no_grad` float ops, same machine, same `torch.set_num_threads(2)`). A miss on this canary makes the WHOLE probe CANNOT_DETERMINE (the tick-tagging instrumentation is suspect, not the underlying finding) -- reported before any partition or ON-arm reading is trusted.

Given the canary holds:
- **ROBUST**: DISC_0.5 gate (a) still passes on >= 4/5 seeds on partition (ii) (ge8) AND on the ON arm's (i) all-states reading (N3's own bar, applied to the fixed substrate).
- **CONFOUNDED**: DISC_0.5 gate (a) drops below 4/5 seeds on partition (ii), OR on the ON arm's (i) all-states reading -- the SAME artefact-diagnosis logic GFLAG-0560 used for W3's `k` (excluding near-reset states, or fixing the substrate, closes or does not close the same gap).
- **MIXED**: neither cleanly (e.g. (ii) still passes but the ON arm does not, or the per-seed pattern is uneven) -- reported with the full per-seed breakdown, not forced into a binary.

**Domain and reporting, stated in advance so this is not over-read:** J_true is E3's own one-step score (N3's own stated limit, "(a) is partly self-consistency"); this probe does not re-open that limit, only the reset-ticks question. FULL is reported for context (N3's own table already showed FULL fails gate (a) on `all` states, 3/5, independent of any reset question) -- a change in FULL's reading under partitioning or the fix is not itself evidence about DISC_0.5's gate status.
