## 1. Verbatim core proposal

> **Specialised cognitive systems may preserve distinct high-dimensional internal representations while
> coordinating through low-dimensional, context-sensitive communication subspaces and low-complexity
> transformations. Development can increase both local specialisation and selective inter-system
> legibility. Replay and sleep may selectively stabilise or reconfigure these interfaces rather than
> globally aligning all representations.**

And the operative experimental principle:

> **Before declaring a representation inadequate, determine whether the needed information is absent,
> merely inaccessible to the native consumer, outside the active communication subspace, dynamically
> incompatible, or present only as a generic channel effect.**

### 7.1 What the synthesis adds

The common requirement may be **reference rather than representational sameness**. A goal system,
hippocampal episode, E1/E2 prediction and downstream world-model consumer can refer to the same
relevant event while retaining different local geometries. What must survive an interface is the
receiver's required relation to that event, together with the conditions under which it is valid.

The existing reference-frame/temporal-gate formulation can organise this:

`effective interface = content × communication subspace × reference frame × receiver context × temporal gate`

This is a diagnostic factorisation, not a measured multiplicative law or a demand for one universal
message format. Recurrent compatibility must also be checked. Each directed boundary specifies only
what its receiver needs and cannot reliably reconstruct: for example event/episode identity, task
context, goal configuration, intended destination, candidate branch, prediction horizon, frame,
provenance or phase validity. These can be implicit population relations; a literal tagged packet is
one engineering possibility, not a biological finding. Phase repeats and therefore cannot alone
uniquely identify an episode or candidate across cycles.

Three distinctions are essential:

1. **Task/goal configuration, intended target and value are different variables.** A stable world state
   can be queried under different goals; goal-ness can be a relation at read time. Neither an orthogonal
   axis nor a single portable goal vector is required in advance.
2. **Cross-registration is weaker than universal translation.** Hippocampus could make two local
   representations recoverably refer to the same episode or trajectory, or retrieve a cue that lets a
   receiver complete its own representation. That does not establish arbitrary conversion between
   cortical codes. The cue-and-native-completion account remains a live rival.
3. **Legibility precedes interpretable disagreement; agreement does not establish truth.** Once systems
   refer to the same candidate and horizon, different consequence estimates can be genuine disagreement.
   A wrong branch match can masquerade as disagreement, and a shared error can masquerade as consensus.

### 7.2 Boundary obligations across the REE systems

These are proposed assay contracts, not new mandatory fields or a chosen substrate.

| Directed boundary | Minimum relation to preserve, when relevant | Characteristic failure |
|---|---|---|
| Goal -> world-model consumer | Which context/configuration and which desired outcome are being evaluated; distinguish desired from observed state | Globally remapping the world to change a goal, or mistaking high value for an intended target |
| Goal <-> hippocampal retrieval | Which episode/object/trajectory relates to the current goal, including provenance and context | Correct memory content assigned to the wrong goal or episode |
| Hippocampus -> E1/E2 | Candidate identity and temporal/frame reference sufficient for the receiving predictor to use the recalled trajectory | A decodable trajectory used as evidence about a different candidate or horizon |
| E1 <-> E2 | Same candidate and action-conditioned transition under compatible horizon semantics; slow context and fast rollout can remain different encodings | Comparing different branches as if their predicted consequences conflict |
| World model -> each consumer | The consumer's required distinctions in its native operating range; private distinctions elsewhere need not be aligned | Rich sender state, plausible external decoding, absent native causal use |
| Reciprocal consumer loop | Retain reference through repeated exchange while permitting uncertainty and substantive disagreement | Stable but wrong agreement, reference drift, or one receiver suppressing another's useful information |

E1/E2 are REE functional roles. None of these studies establishes E1 = hippocampus, E2 = PFC, or a
one-to-one neuroanatomical assignment. A shared core plus private representations, the ARC-121 common
object, and boundary-specific translations remain comparative alternatives.

### 7.5 Falsifiable discriminators, not queued experiments

Apply the existing ladder: encoded -> externally decodable -> native-accessible -> bridgeable ->
pairing-specific -> causally used -> behaviourally beneficial. Decoder performance alone is D1, not
native causal use or behavioural benefit. Use frozen endpoint snapshots, held-out contexts and the
least expressive bridge; match training data, capacity, compute and intervention exposure as relevant.
No test below authorises bypassing existing assay-readiness or governance gates.

1. **Factorised goal relation versus global remapping.** Cross context/configuration, intended target,
   sensory state and value rather than confounding them. Fit on some combinations and test new ones.
   Perturb the candidate goal relation while checking preserved state/transition use. Selective target
   reassignment with intact world competence favours factorisation; a matched global-map account that
   predicts transfer equally well defeats a claimed advantage. A clean plotted axis is insufficient;
   failure of linear orthogonality alone does not refute relational factorisation.

2. **Hippocampal cross-registration versus retrieval alone.** Hold episode content, cue usefulness and
   exposure constant; compare correct cross-area event pairings with within-context shuffled pairings.
   Measure the actual receiver's interpretation of held-out episodes, not just retrieval accuracy.
   If cue-triggered native completion matches a learned pairing map, universal translation is unnecessary.
   If pair identity never matters despite sensitive controls, the proposed pairing-specific mechanism
   has not earned explanatory work at that boundary.

3. **E1/E2 branch identity versus generic helpful input.** Keep the marginal trajectory content fixed
   while scrambling candidate or horizon correspondence. A consistent relabelling at both ends is a
   positive control: it should preserve performance. Corrupting only one end should selectively damage
   candidate-specific consequence use, rather than simply reducing arousal or signal strength. If
   performance survives a verified correspondence corruption, explicit branch identity is unnecessary
   at that locus or reconstructed by another route; distinguish those possibilities before concluding.

4. **Theta addressing versus gain and permissive timing.** Cross content identity, receiver state and
   phase. Compare correct, wrong, shifted and random phase at matched event count, power/energy,
   occupancy and plasticity budget. A phase-conditioned map must beat a complexity-matched static map
   and scalar-gain model out of sample. Wrong-phase delivery must change *which content the receiver
   uses*, beyond weakening transmission, to support addressing. Control cycle/event identity and common
   inputs; cross-area coherence by itself cannot pass this discriminator.

5. **Replay repairs an interface versus improves a memory.** Reuse INV-110's six gates: measured drift;
   preserved local information at both ends; lost native cross-area use; correct-pair replay versus
   matched shuffled pairing; restored held-out causal use; and superiority to ordinary replay, stable
   mappings and fast local adaptation under matched budgets. Freeze endpoint probes before and after;
   report bridge complexity as a secondary diagnostic. Better recall, coactivation or general cortical
   learning without these gates supports consolidation, not the specific maintenance mechanism.

6. **Developmental mediation gives way to direct interfaces.** Separate chronological maturation,
   cumulative experience and memory age. Test early/late hippocampal interruption and direct cortical
   pathway interruption for familiar, novel and remapped tasks. A handover predicts declining mediator
   dependence with increasing direct-path necessity for familiar relations, while novelty may restore
   mediation. Reduced activation alone fails. For the REE developmental-history claim, retain the
   reinitialised-final-architecture control and matched final capacity/curriculum; successful adult
   consolidation alone cannot establish an ontogenetic pruning mechanism.

7. **Consumer-specific world-model surfaces versus a hidden second solver.** Fit small boundary maps
   to the relations each consumer requires; test native causal use under a held-out consumer/context
   change while monitoring sender-private competence. Compare a shared core/common object and equally
   budgeted individual maps. If only an expressive decoder learns the task afresh, no evidence of a
   usable existing surface has been obtained. If a common object transfers as well, do not multiply maps.

8. **Dynamic consensus versus forced agreement.** First verify that the populations refer to the same
   candidate. Perturb agreeing and disagreeing modes with matched amplitude and compare reciprocal,
   feedforward and shuffled-feedback systems. Require preservation of reference and useful uncertainty
   through recurrence, not simply decreasing population distance. Shared false evidence and legitimately
   different self/other estimates are negative controls: a system that makes those agree indiscriminately
   has not demonstrated better integration.

### 7.6 What the four searches change

The [targeted tranche](hippocampal_translation_maps_literature_tranche_4_goals_branches_replay_development.md)
provides nonspatial context/abstraction evidence, contextual hippocampal–OFC coordination, stronger
causal downstream replay findings and developmental counterexamples. It leaves three central debts
open: a causally read cross-area branch/horizon identity; replay repair that meets the existing
interface-specific standard; and an ontogenetic transition to demonstrably direct cortical mappings.
Those are bounded research questions. They are not absence-of-evidence proofs and do not alter any
registered claim's status, confidence, implementation phase or queue priority.
