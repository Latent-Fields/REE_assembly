## 1. Conflicts chosen, and why

Deliberate spread: two clean resolution cases (H1), one irreducible-persistence case
(H2), and one **adversarial dissociation case** chosen to attack the primary validity
threat (Section 4 of the study) head-on -- a topic whose opinion axis resolved but whose
humour died the "wrong" way.

| # | Conflict | Role | Why chosen |
|---|----------|------|-----------|
| C1 | Homosexuality / same-sex marriage (US, ~1975-2020) | **Resolution (H1)** | Best longitudinal opinion data; clearest target-flip; **contains both deaths inside one topic** -- the ideal instrument test |
| C2 | Interracial marriage / overt racism (US, ~1955-2015) | **Resolution (H1)** | Longest opinion series (Gallup 1958-2021); a legislative anchor (Loving, 1967) far ahead of opinion; an unusually *early* target-flip (Archie Bunker, 1971) |
| C3 | Mortality / death | **Persistence (H2)** | Cleanest genuinely-irreducible tension; no resolution axis exists *by construction*; predicts a flat, non-dating curve |
| C4 | Gender-role "nagging-wife / mother-in-law" jokes (US, ~1950-2005) | **Adversarial** | Opinion axis **did** resolve (GSS FEFAM), yet the humour died predominantly by *taboo-death*, not the H1-predicted resolution-death flip. Tests whether the code over-claims |

Anti-circularity check (study Section 3): every resolution axis below comes from
opinion/legislation data **only** -- none is inferred from the humour. C3's "axis" is
irreducibility, not an opinion curve, so it cannot be circular either.

modest and illustrative (~a dozen dated instances each), assembled from cultural memory +
light search. **They are NOT a corpus** and carry the analyst-hindsight caveat in
Section 5.

## 4. Eyeball question (a): does the code separate resolution-death from taboo-death?

**Yes -- and non-trivially.** On every case where a topic left mainstream humour, the
target-of-violation code produced a discriminating reading rather than rubber-stamping
"topic vanished -> resolved":

- C1: out-group form -> **taboo-death** (Tracy Morgan 2011); old-norm form -> rose then
  resolution-died. Two different fates, two different codes.
- C2: out-group form -> **taboo-death** (Richards 2006); old-norm form (Archie) ->
  persisted/rose. Separated.
- C4: out-group form -> **taboo-death**; old-norm flip weak/late -> the code correctly
  reads *taboo*, and correctly flags that the resolution-death signature is **absent**
  even though opinion resolved. The code **dissents** from the naive inference -- the
  strongest possible evidence that it is doing real work.

**Gate (i) is met.** The instrument is coherent and discriminating. The one caveat is the
"whose butt is it?" ambiguity (Archie), which is a reliability problem, not a validity
one -- addressable with an inter-rater protocol.

## 5. Eyeball question (b): does humour shape + target-flip track the axis, lead or lag?

**Relation: yes. Direction: leads in the clean cases -- but the lead is not trustworthy
from a hand sample.**

| Conflict | Opinion midpoint | Humour target-flip | Lead / lag |
|----------|-----------------|--------------------|-----------|
| C1 | 2011 | ~1997-2008 | humour **leads** ~5-12y |
| C2 | ~1994-95 | ~1971 (Archie) | humour **leads** ~20y |
| C3 | (none) | (none -- flat) | correctly no relation |
| C4 | ~1985 | weak/late; death is taboo not flip | humour **lags / dissociates** |

Two honest qualifications, both material:

**5a.** In the two clean resolution cases the target-flip *precedes* the opinion midpoint
-- the direction SOC-HUM-1's causal reading needs. But this "lead" is **highly vulnerable
to analyst hindsight**: I retrieved these instances from cultural memory, and memory
preferentially preserves the examples that *became legible as resolution-consistent*.
This is the study's own survivorship/hindsight confound (Section 4) operating on the
**analyst**, not just the corpus. A hand-spike **cannot** cleanly establish lead-lag; the
apparent lead is suggestive at best and partly manufactured by the retrieval process.

**5b.** C4 is a **partial counterexample to H1's strong form**: a norm resolved
(~1985) with only a weak, late target-flip -- the humour died by taboo, not by the
predicted resolution-death flip. So resolution can occur **without** the humour doing the
flip. This bounds SOC-HUM-1: humour-work is *one* route to (or marker of) resolution, not
a necessary precursor. Humour-death is therefore **not** a clean proxy for resolution
direction; the target-flip is the load-bearing signal, and its **absence does not imply
non-resolution**.

**Gate (ii) is met** at the required bar -- there is a real relation between humour
trajectory/target-flip and the independent axis, and it plausibly leads in clean cases.
The gate does **not** require establishing causal lead-lag, which is fortunate, because
the spike cannot.

## 6. GO / NO-GO verdict and conditions

**GO (qualified).** Both gate conditions (study Sections 9-10) are met on cases
hand-picked to meet them: the target-of-violation code separates resolution- from
taboo-death (gate i), and humour trajectory + target-flip relate to the independent
opinion axis (gate ii). The instrument is coherent enough to be worth building.

This is a GO to build the **instrument**, explicitly **not** a confirmation of the
**causal thesis**. Three conditions the spike surfaced, each a pre-registered guard for
the corpus phase:

1. **Quarantine lead-lag until dated primary sources replace memory.** The apparent
   "humour leads opinion" result (5a) is contaminated by analyst hindsight and must not be
   carried forward as evidence. The corpus phase must date every instance from a primary
   source (special/broadcast air date, cartoon publication date) and compute the lead-lag
   only from that dated series -- never from recalled examples.

2. **Make the C4 cell ("opinion resolved, humour taboo-died") a first-class outcome, not
   noise.** H1's "resolution is preceded by a target-flip" is bounded, not universal (5b).
   The coding manual must record taboo-death-without-flip as a distinct, expected outcome,
   and H1 should be restated as a *sufficient-signal* claim (a flip that leads is evidence
   of humour-work) rather than a *necessary-precursor* claim.

3. **Build inter-rater reliability into the target-of-violation code first.** The whole
   instrument rests on this one code, and the Archie-Bunker ambiguity ("whose butt is it?")
   shows the code is genuinely contestable per-instance. Specify the coding manual and run
   a two-rater agreement check on a held-out sample **before** any scaled prevalence
   computation. If raters cannot agree on target, the instrument fails regardless of how
   clean the opinion axes are.

A clean NO-GO was genuinely on the table -- the lead-lag circularity (5a) is a real reason
to doubt the headline causal claim. It is **not** a reason to abandon the study, because
the gate tests instrument coherence, not the causal claim, and instrument coherence is
robustly demonstrated (especially the two-deaths separation in Section 4, which is a
documented pattern, not a subtle inference). The honest decomposition is: **instrument =
GO; causal thesis = not yet tested, and untestable by hand.**

## 7. What the next step needs (if GO)

Per study Section 10, the next node is the target-of-violation **coding manual + inter-rater
reliability** (condition 3 above), running in parallel with **sourcing the independent
opinion series** (Gallup SSM, Gallup interracial-marriage, GSS FEFAM already anchored here;
add Pew acceptance-of-homosexuality and any Eurobarometer cross-checks). Only after the
coding manual clears an inter-rater check should corpus assembly + topic modelling begin --
and the lead-lag analysis stays quarantined (condition 1) until it runs on dated primary
sources. This remains a `/lit-pull` + design thread, not a `/queue-experiment` substrate
run.
