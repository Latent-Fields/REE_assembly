## 1. Verbatim core proposal

> **Competent integrated behaviour depends not on maximising intermodule information flow, but on
> dynamically governing its selectivity, stability, repertoire, and causal timing.**

And the distinction the whole family turns on:

> A system may contain information, and may even exchange large amounts of information, while still
> lacking an organisation that determines which information is permitted to become causally
> influential where and when.

The minimal message model:

```text
m_i->j(t) = g_ij(t) * W_ij(h_i(t))
```

with `g_ij(t)` -- "At this moment, how much jurisdiction does `i` have over `j`?" -- as the new
object.

## 3. Key formulations (verbatim)

- "the organism continuously constructs a spatiotemporal pattern that determines which
  otherwise-available information can effectively influence which downstream process next."
- "Even when a representation exists and a valid transformation exists, **when is that transformed
  message allowed to matter?**"
- "A representation can therefore be intact but causally silent. A transformation can be correct but
  unavailable at the wrong time."
- "content absent -> routing hypothesis cannot rescue / content present + native use absent ->
  routing/interface hypotheses become admissible."
- "a dynamically compatible transformation may still require correct **temporal access** to become
  causally useful."
- "The decisive anaesthesia-like result is not reduced traffic. It is: behaviour deteriorates while
  total intermodule transfer is matched or increased."
- "A wake-like REE signature would not simply maximize transfer. It might instead occupy a regime in
  which transfer is **sparse enough to be selective, rich enough to be flexible, stable enough to
  complete a computation, and dynamic enough to change with context**."
- "not a travelling packet of thought, but a travelling frontier of causal privilege across the
  cognifold."
- "The first field must be content-poor and capacity constrained."
- "If the best model consists of abrupt switching between global routing modes, retain the
  information-governance result and discard the travelling-wave analogy. That would still be
  scientific progress."
- On process: "This thought should **not** immediately create a new permanent REE module ... The
  first concrete design deliverable should therefore be a **dynamic-routing companion
  specification** for the existing communication-subspace/bridge instrument, not an implementation
  in `ree_core`."
