## 3. Biological-reference triage — sleep spindles, sensory gating, and content packaging

The closest mammalian reference for the `spindle_density` DV is thalamocortical sleep spindles (11–16 Hz NREM stage-2 oscillations). In biology these serve **two coupled functions**, both already in this codebase's literature corpus (`evidence/literature/targeted_review_connectome_mech_122/`): (1) **content packaging/selection** — spindle-coupled hippocampal ripples show elevated mediodorsal thalamus firing associated with content transfer (Yang, Logothetis & Eschenko 2018/2019, J Neurosci; also Ngo 2020, Staresina 2015), and (2) **sensory gating/protection** — spindle-uncoupled ripples show *suppressed* thalamic firing, interpreted as a thalamic relay "step-aside" protecting the consolidating trace from interruption.

REE's claim for exactly this coupled mechanism is **MECH-122**: *"Thalamo-cortical spindle-equivalent bursts package E3/hippocampal replay content for z_theta delivery AND gate external sensory input, protecting the consolidation episode from interruption."* MECH-122's own registration notes (2026-03-23) and `evidence_quality_note` read "V4 scope" / "V4-scope mechanism" / "pending V4 implementation" — **this prose is stale, not the claim's `implementation_phase: v3` field.** Per [[feedback_phase_label_follows_dependency]] (recorded the same day, session `mech-loop`, and independently re-confirmed by the user in this session): a claim's phase label is a roadmap prediction, not a permission gate — if a claim is a genuine dependency of live V3 work, it is V3-scoped by definition, and the correct fix is to update the stale descriptive prose, not the enum field.
