# Hippocampal translation maps — biological/computational evidence campaign

**Date:** 2026-09-09  
**Status:** research campaign / evidence-intake scaffold; not a claim registration, implementation decision, or experiment-queue mutation  
**Parent archaeology:** `docs/thoughts/2026-09-09_hippocampal_translation_maps_ree_archaeology.md`  
**Related REE work:** mutual legibility, receiver-conditioned translation, shared reference frames / temporal gates, developmental ontology and replay, developmental overcapacity / pruning, z_world representation contract, V3-EXQ-978 → 1002 → 1008 → 1010

## Campaign purpose

The archaeology established that REE has several convergent internal lineages around a common problem: specialised systems can preserve useful information yet fail to make it usable by another system because the relevant relation is expressed in the wrong form, frame, phase, or interface geometry.

It did **not** establish that hippocampal circuitry is a generic translation engine.

This campaign therefore asks a narrower biological/computational question:

> **What do hippocampal–entorhinal circuits actually map between, how are those mappings learned and remapped, which relational/reference-frame invariants survive across representational changes, how does replay affect those mappings, and is there evidence for cross-system mediation that cannot be explained more simply by episodic retrieval, navigation, routing, or ordinary associative memory?**

The campaign is designed to be capable of weakening the translation-map hypothesis.

---

## 1. Candidate roles to distinguish

Do not pool all hippocampal involvement under “translation”. Code evidence separately for at least five candidate roles.

### R1 — relational indexing

The hippocampal/entorhinal system binds episode, context, position, action, consequence, temporal order, and other relations so that multiple systems can refer to the same event without sharing identical internal coordinates.

**Strong evidence would require:** a shared relational variable demonstrably organizing cross-system interaction or transfer, not merely successful episodic memory.

### R2 — reference-frame mediation

The system participates in transformations or mappings between frames such as egocentric ↔ allocentric, local ↔ global, object-centred ↔ self-centred, temporal sequence ↔ episode structure, or action-relative consequence coordinates.

**Strong evidence would require:** frame-specific remapping or causal disruption of cross-frame use while basic content remains available.

### R3 — query-conditioned retrieval / receiver-conditioned exposure

Which part of a stored representation becomes available depends on current task, cue, receiver state, candidate action, or prediction context.

**Strong evidence would require:** matched memory content yielding different selectively useful retrieval according to receiver/query state, with controls for generic attention or retrieval strength.

### R4 — replay-based interface maintenance

Offline replay may maintain or re-establish relationships between representations as cortical/hippocampal codes change with learning, development, or remapping.

**Strong evidence would require:** replay-dependent preservation or restoration of cross-system mapping/transfer beyond simple strengthening of memory traces.

### R5 — developmental scaffold / pruning

Immature hippocampal–cortical interactions may permit broad/overcomplete associations that later become sparse, structured, and selectively useful.

**Strong evidence would require:** developmental-history dependence at matched mature capacity/structure, not merely age-related sparsification.

## 2. Evidence streams

### Stream A — coordinate transforms and reference frames

Target literature on:

- egocentric/allocentric transformations;
- place, grid, head-direction and object-vector coding;
- retrosplenial, parietal, entorhinal and hippocampal coordinate transformations;
- local/global remapping;
- relational coding beyond physical space;
- task/goal/action-centred spatial representations.

For each paper code:

1. what the source representation is;
2. what the target/consumer representation is;
3. whether a genuine transform is measured or merely correlated;
4. whether the transformation is hippocampal, entorhinal, retrosplenial/parietal, distributed, or unresolved;
5. whether causal evidence exists;
6. whether a simpler navigation/indexing account explains the result.

### Stream B — relational and structural representations

Target:

- cognitive-map theories;
- relational memory;
- successor-like / predictive map accounts;
- abstract task-state or graph representations;
- inferential transfer across separately learned relations;
- hippocampal coding of latent task structure.

Question:

> Does hippocampal structure provide a shared relational coordinate that lets otherwise differently encoded information become mutually usable?

A useful positive result must exceed “hippocampus represents abstract structure”.

### Stream C — hippocampal ↔ cortical communication and routing

Target:

- hippocampal–prefrontal coordination;
- hippocampal–sensory cortical reinstatement;
- entorhinal gateway/routing functions;
- oscillatory phase / theta-gamma / ripple-linked communication;
- directionality and content-specific coupling;
- context-dependent cortical targets of hippocampal output.

Separate:

```text
channel present
content-specific transfer
receiver-conditioned transfer
temporal-gating effect
causal downstream use
```

Do not infer translation from coherence/coupling alone.

### Stream D — replay, consolidation and representational drift

Target:

- sharp-wave-ripple replay;
- cortical reinstatement;
- systems consolidation;
- hippocampal representational drift;
- stable behaviour despite changing local codes;
- reactivation-driven remapping;
- sleep-dependent schema integration;
- replay timing relative to cortical plasticity.

Central discriminator:

> Does replay preserve/restore **relational continuity across changing codes**, or does it simply strengthen/rehearse the same memory?

### Stream E — pattern completion, cue dependence and query-conditioned retrieval

Target:

- CA3 pattern completion/separation;
- cue-dependent retrieval;
- context gating;
- goal-dependent memory retrieval;
- prospective / trajectory-dependent hippocampal activity;
- prefrontal/hippocampal interactions that select which memory is expressed.

A translation-like interpretation requires showing that retrieval is rendered in a form useful to the current consumer/query rather than merely returning a stored episode.

### Stream F — development and pruning

Target:

- CA3 recurrent connectivity development;
- hippocampal–entorhinal maturation;
- developmental changes in remapping/generalisation;
- synaptic overproduction/pruning where directly relevant;
- developmental emergence of sparse structured codes;
- critical-period or history-dependent relational learning.

Retain the existing REE distinction:

```text
large → prune/distil
vs
same final sparse architecture trained from infancy
```

Biological evidence need not instantiate this exact artificial assay, but should be coded for genuine history dependence.

### Stream G — negative and alternative explanations

Actively seek findings favouring:

- ordinary episodic retrieval;
- generic associative learning;
- routing without translation;
- attention/arousal explanations;
- common-input explanations;
- cortical rather than hippocampal coordinate transforms;
- local remapping without preserved cross-system relational invariants;
- replay as strengthening rather than interface maintenance;
- end-to-end co-adaptation that makes an explicit mapping unnecessary.

This stream is mandatory, not optional red-teaming after the positive literature is assembled.

## 3. Evidence coding matrix

For each source record:

| Field | Coding question |
|---|---|
| Biological system | hippocampus / CA1 / CA3 / DG / MEC / LEC / RSC / PFC / sensory cortex / distributed |
| Sender | what representation/state originates the relevant content? |
| Receiver | what system consumes or is altered by it? |
| Relation/frame | what invariant or coordinate is shared/transformed? |
| Query/context | does receiver state/task/cue condition the transfer? |
| Timing | is efficacy phase-specific? |
| Transformation evidence | direct transform / representational alignment / transfer / only correlation |
| Causal evidence | lesion / stimulation / perturbation / none |
| Replay role | none / reinstatement / strengthening / remapping / interface maintenance candidate |
| Developmental evidence | absent / correlational / history-dependent |
| Alternative explanation | strongest simpler account |
| REE role | R1–R5 |
| Epistemic weight | established / suggestive / analogy only / negative |

## 4. Strong falsifiers / hypothesis-weakening outcomes

The hippocampal translation-map synthesis should weaken if the literature shows that:

1. reference-frame transforms are consistently implemented outside hippocampal/entorhinal circuitry and hippocampal activity merely inherits the result;
2. cross-system transfer can be explained by standard episodic reinstatement with no evidence for shared relational indexing;
3. query/context effects reduce to generic retrieval strength or attention;
4. replay improves memory but does not preserve/restore cross-representational transfer or mapping complexity;
5. representational drift is handled by local plasticity without any identifiable relational continuity mechanism;
6. developmental sparsification has no evidence of functional history dependence;
7. causal perturbations alter memory quantity/strength but leave proposed cross-frame/interface operations intact;
8. apparent “translation” disappears when common input, task difficulty, or global state is controlled.

## 5. Assay mapping back into REE

The literature campaign should inform, not replace, the assay family already recorded in the archaeology.

| Biological question | REE assay |
|---|---|
| Is a simple transform sufficient? | translation-complexity ladder |
| Does receiver/query state matter? | `T(A)` vs `T(A,B)` + receiver permutation |
| Does a relational frame matter? | reference-frame permutation |
| Is communication example-specific? | correct-pair vs wrong-pair / zero / random |
| Does phase matter? | target/early/late/shuffled temporal gate |
| Is one-step success stable recurrently? | recurrent-stability assay |
| Does developmental history matter? | small vs large→prune vs large vs reinitialised-final |
| Does replay repair mutual legibility? | replay-remapping assay |

The biological campaign should not be used to install hippocampal machinery directly into V3. It should narrow which mechanisms deserve synthetic tests.

---

## 6. Relationship to V3-EXQ-1010

This campaign remains useful whichever way 1010 resolves.

If high-capacity nonlinear recovery succeeds, interface/translation complexity becomes an immediate V3 concern and biological evidence may help rank constrained alternatives.

If recovery fails under valid guards, the immediate V3 bottleneck is sender/encoder-side content loss, but later E1/E2/hippocampal/E3 mutual-legibility questions remain.

Therefore 1010 changes urgency, not the campaign question.

## 7. Deliverables

The campaign should eventually produce:

1. a source-by-source evidence matrix;
2. a narrative synthesis separating R1–R5;
3. a negative-evidence / alternative-explanation section;
4. a map from biological evidence to REE assays without architectural promotion;
5. explicit statements of which parts are established neuroscience, which are plausible computational analogies, and which remain REE-specific hypotheses;
6. only after that, a decision on whether any claim/intake update is justified.

## Compact campaign rule

> **Do not ask whether the hippocampus “translates representations” in the abstract. Ask which relation is preserved, between which systems, for which receiver/query, at which phase, by what causal mechanism, and whether a simpler retrieval/indexing/routing account survives.**
