# Kahneman, Treisman & Gibbs (1992) -- The reviewing of object files

According to PubMed (PMID 1582172; [DOI](https://doi.org/10.1016/0010-0285(92)90007-O)), this is the paper that introduced the *object file* -- a temporary, episodic representation that a perceiver opens for an object and then continuously updates as that object is encountered again across motion, occlusion, and time. Across a series of object-specific priming experiments, a target letter was named faster when it appeared on an object that had previously carried that same letter, even after the object moved or was briefly hidden. The information was *reviewed* -- re-linked to the existing file rather than re-encoded from scratch. The load-bearing finding for us is not the priming effect itself but what it implies: object correspondence is an **actively maintained** relation, recomputed as the input evolves, not a one-shot binding fixed at first sighting.

That is exactly the premise MECH-456 rests on. The claim asserts that in REE the self-anchor <-> world-configuration binding held by the `cross_stream_binder` is *maintained, not intrinsic* -- the binder monitors whether the currently-bound configuration is still the best-supported one and re-binds when a competitor overtakes it. Before you can argue that a rebinding *event* does functional work, you need the prior claim that binding is the kind of thing that is continuously re-evaluated at all. Kahneman, Treisman and Gibbs give the cleanest and oldest evidence that biological perception treats a bound entity as an updatable file whose correspondence is under constant review. It is the conceptual root of the whole entity-rebinding lineage.

Where I want to stay honest is the gap between *updating a file* and *switching to a different file*. Object-file reviewing is largely evidence for **continuity** -- the system works hard to keep treating a stimulus as the same object. That is, if anything, the counterweight to rebinding: the stability bias that a rebinding threshold must overcome (a theme the Manassi meta-analysis in this dossier makes explicit). The paradigm does not force a competing object to *overtake* the current file and win the correspondence. So this paper grounds one half of MECH-456 firmly (binding is an active, updatable correspondence) and leaves the other half -- the prediction-error-driven overtake trigger -- to the Weilnhammer, Cole, and Gershman entries.

The transfer risk is the obvious one and I have priced it in. This is 1992 human visual-attention psychophysics operating over sub-second displays; REE's binder is a trained bilinear scorer over latent streams operating within a foraging episode. The mapping is analogical -- the claim itself labels its biological grounding a *non-formal import* -- and none of REE's binder behaviour is measured here. That is why I put source quality high (0.85, this is bedrock) but mapping fidelity only moderate (0.62) and transfer risk elevated (0.45), landing at an aggregate 0.66. It is a genuine, load-bearing grounding for the premise of the mechanism; it is not, and cannot be, evidence that REE's binder rebinds functionally. That burden sits with the V3-EXQ-733a functional test.
