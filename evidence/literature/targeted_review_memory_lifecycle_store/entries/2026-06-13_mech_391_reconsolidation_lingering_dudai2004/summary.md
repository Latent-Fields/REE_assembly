## Dudai & Eisenberg 2004 -- reconsolidation as 'lingering consolidation' (grounds, and bounds, the 'contested' state)

According to PubMed, Dudai and Eisenberg's 2004 *Neuron* review ([DOI](https://doi.org/10.1016/j.neuron.2004.09.003)) takes up a question that bears directly on whether a memory-lifecycle store should have a `contested` state at all: once a memory is consolidated, can it become labile again? The textbook answer had been no -- consolidation starts and ends once per item. The reconsolidation literature revived the opposite view: that reactivating a memory returns it to a state sensitive to amnestic agents, from which it must re-stabilise. Dudai & Eisenberg accept the phenomenon but reframe it. On the weight of the data they argue reconsolidation is *lingering consolidation* -- a tail of the original stabilisation process, occurring mainly in relatively fresh memories -- rather than a full recapitulation, and they note that blocking it does not induce permanent amnesia.

For MECH-391 this is a useful, deliberately double-edged grounding. It supplies the biological warrant for the `contested` state: a trace that had settled can be reactivated into a condition where it is once again open to revision. That is exactly the lifecycle transition REE wants to name -- a memory leaving a stable state and re-entering one where it can be updated, challenged, or overwritten. Without something like reconsolidation, a `contested` state would be a pure design invention; with it, the state has a substrate analogue.

But the same paper is why I have marked this `mixed` rather than `supports`. Dudai & Eisenberg's careful reading bounds the phenomenon in two ways that matter for the design: the labile window is largely confined to fresh memories, and it may be a lingering tail rather than a recurrent, always-available mode. A lifecycle store that modelled `contested` as a standing, indefinitely re-writable slot would over-read this biology. The honest translation is that a memory's eligibility to enter the contested state is itself gated -- by recency, by reactivation, and possibly by how settled the trace already is -- and the REE state should carry that eligibility window rather than treat re-writability as permanently on tap.

I rate this 0.62, `mixed`. The source quality is high and the existence of a reactivation-induced labile state is well-grounded; the discount reflects the genuine caution the paper raises against an unbounded reading. `exp_conf` stays 0; promotes nothing.
