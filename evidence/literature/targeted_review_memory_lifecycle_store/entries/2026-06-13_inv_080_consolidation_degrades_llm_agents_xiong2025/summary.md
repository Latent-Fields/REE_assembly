## Xiong et al. 2025 -- preserve episodic records over lossy consolidation (computational corroboration of INV-080)

This is the secondary consolidation-faults source noted in the MEM-8 node (arXiv:2505.16067), re-verified on 2026-06-13. The paper -- "How Memory Management Impacts LLM Agents: An Empirical Study of Experience-Following Behavior" (Xiong, Lin, Xie, He, Liu, Tang, Lakkaraju, Xiang; v1 May 2025, v2 Oct 2025; [arXiv:2505.16067](https://arxiv.org/abs/2505.16067)) -- is an empirical study of how memory-management choices change LLM-agent behaviour. Its central observation is an *experience-following property*: when a task input is highly similar to the input stored in a retrieved memory record, the agent's output is highly similar too. That property cuts both ways. It is useful when the stored experience was good; it is a liability when the stored experience was wrong, because the error propagates directly into the new output. The authors' recommendation is the part that corroborates INV-080: regulate experience *quality* within the memory bank -- using future task evaluations as free quality labels and preserving/filtering episodic records -- rather than transforming memory through consolidation or summarisation steps that lose information.

This lands on INV-080 from the agent side of the house. INV-080's claim is that a consolidated abstraction must retain a pointer to, and must not delete, the source episodes it abstracts. Xiong et al. give an empirical reason this matters operationally: the signal you need to *detect and filter a bad experience* -- the episodic detail and its downstream evaluation -- is exactly what a lossy consolidation step throws away. Summarise the episode into gist and you lose the evidence that would later let you mark it low-quality and stop following it. So consolidation without preserved, quality-labelled raw episodes is not merely lossy; in an agent loop it is actively error-propagating. That is the same logic as the primary consolidation-faults source the node already verified (arXiv:2605.12978, agents preserving raw episodes double the accuracy of forced-consolidation), now corroborated by a second, independent study.

The honest discount is twofold and I have kept the confidence at 0.60 to reflect it. First, this is an AI-agent preprint, not peer-reviewed and not biology -- under the project's biology-before-formal-definitions rule it *supplements* the biological warrant (Frankland & Bontempi, Dudai & Eisenberg, Nader & Hardt, Sekeres/Winocur/Moscovitch, Richards & Frankland) rather than substituting for it. Second, transfer risk is real: specific LLM-agent memory architectures may not generalise to REE's substrate. It is mitigated by the fact that REE is itself an agent with a retrieval-and-reuse memory loop, so the domain gap is narrower than an animal-to-human transfer -- but it is not zero.

I rate this `supports` at 0.60, tagged to INV-080 as computational corroboration. `exp_conf` stays 0; promotes nothing.
