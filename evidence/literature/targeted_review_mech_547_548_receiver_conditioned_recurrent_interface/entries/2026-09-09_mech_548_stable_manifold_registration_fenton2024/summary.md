# Fenton 2024 — stable relational structure beneath apparent remapping

Nature Reviews Neuroscience 25:428–448, DOI `10.1038/s41583-024-00817-x`, PMID `38714834`.

The perspective argues that place-field remapping can coexist with relatively stable subsecond co-firing relationships and internally organised population manifolds. One useful interpretation is that a stable internal manifold is **registered to different environments** rather than completely rebuilt each time local place-field expression changes.

This matters for MECH-548 because raw coordinate drift is not necessarily interface failure. A good recurrence assay should ask whether the relation needed by the consumer remains stable, not whether individual dimensions or units remain fixed.

It is also a rival to an over-strong clean-base story: if a bridge can attach to a stable relational manifold, recurring use may remain coherent without explicit restoration of a pristine receiver state. Thus this source motivates the stability problem while constraining how drift should be measured.
