# Teyler & Rudy 2007 — hippocampal indexing as a rival to translation

Hippocampus 17(12):1158–1169, DOI `10.1002/hipo.20350`, PMID `17696170`.

The indexing account proposes that hippocampus stores an index over the distributed cortical activity belonging to an episode. A partial cue can activate that index and thereby reinstate the appropriate cortical pattern.

For the translation-map programme this is important **negative discipline**. The system can coordinate heterogeneous representations without translating cortical latent A into cortical latent B. It can instead retrieve the correct relational/index state and cause the appropriate target representation to be reinstated.

That makes indexing a first-class rival to MECH-547. If a low-complexity index/reinstatement mechanism explains a future `T(A,B)` gain, receiver-conditioned translation should not inherit the evidence. Conversely, if receiver-state permutation destroys a gain after indexed retrieval and sender-only controls are matched, MECH-547 would survive this rival.
