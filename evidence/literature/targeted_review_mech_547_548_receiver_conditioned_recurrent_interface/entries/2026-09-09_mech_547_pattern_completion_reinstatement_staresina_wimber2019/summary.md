# Staresina & Wimber 2019 — pattern completion and cortical reinstatement

Trends in Cognitive Sciences 23(12):1071–1085, DOI `10.1016/j.tics.2019.09.011`, PMID `31672429`.

The review integrates human electrophysiological work into a temporal retrieval sequence: a cue reaches medial temporal structures, hippocampal pattern completion begins, and the target memory is then reinstated in cortex. Recall is therefore not a static readout of everything stored; it is a temporally organised process that selects and reconstructs task-relevant content.

For MECH-547 this is supportive at the level of **query-dependent exposure**. It also strengthens the temporal-gating sibling thought. But the same observations are compatible with hippocampal indexing/pattern completion and do not require the bridge itself to inspect the receiver state. The registered sender-only and receiver-permutation controls remain decisive.
