# Increasing Transparency Through a Multiverse Analysis (Steegen, Tuerlinckx, Gelman & Vanpaemel, 2016)

Constructing an analysis-ready dataset from raw data almost always involves choices that are individually defensible but collectively arbitrary: which cases to exclude, how to transform a variable, how to code an ambiguous response. The standard practice of picking one such combination of choices, running the analysis, and reporting the result hides how much of the conclusion depends on those largely arbitrary decisions rather than on the phenomenon itself. Steegen and colleagues propose an alternative: a "multiverse analysis" that identifies every reasonable processing option at each decision point, constructs the full combinatorial set of resulting datasets, and reruns the identical analysis across all of them. The result is not a single number but a distribution -- and the shape of that distribution (tight and consistently significant, versus wildly dependent on which arbitrary choice was made) is itself the evidence. Their worked example, a re-analysis of a published finding linking fertility to religiosity and political attitudes, shows the original conclusion was substantially more fragile than the single-pipeline analysis suggested.

This paper is a direct, citable, formal answer to one of the specific literature-mining requests in GOV-BEHADJ-1's source thought: "statistical methods for multi-metric adjudication." The source thought's own "Adjudicate" workflow step is currently stated only qualitatively -- "judge the pattern of evidence across measures and perturbations rather than allowing one metric to define the phenomenon" -- without a concrete procedure for how that judgment should actually be performed or reported. Multiverse analysis supplies exactly that missing procedure. Applied to a REE behavioral question, it would mean: rather than picking one definition of "reversal" (a fixed turn-angle threshold) or one windowing choice for "excursion duration," enumerate the reasonable range of such definitional choices, rerun the same hypothesis test across all of them, and report whether the conclusion (e.g. "post-sleep trajectories showed fewer reversals") holds robustly across that space or depends on one particular, arbitrary parameterization.

This also gives the source thought's anti-Goodharting checklist a formal backbone. "Could the metric improve while the behaviour of interest worsens, or vice versa?" is, in multiverse-analysis terms, a question about whether the metric's behavior is stable across the space of reasonable alternative operationalizations of the same underlying construct -- if it is not stable, the metric is likely tracking something narrower and more arbitrary than the phenomenon it was meant to index, which is precisely the Goodharting failure mode the source thought warns against.

The mapping caveat is that the paper's own worked example is survey/questionnaire data, where the "reasonable choices" are things like exclusion criteria and item coding. REE's analogous choice space -- smoothing windows, reversal-detection thresholds, state-boundary definitions for continuous behavioral time series -- is not addressed by the paper and would need to be built out separately if this method were adopted. The multiverse-analysis literature itself also flags that a large combinatorial choice space creates its own multiple-comparisons interpretation burden, which is not a fully solved problem and would need careful handling in any REE implementation.
