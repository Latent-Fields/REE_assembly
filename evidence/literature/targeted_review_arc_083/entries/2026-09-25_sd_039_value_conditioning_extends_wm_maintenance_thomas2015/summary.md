# Value Conditioning Modulates Visual Working Memory Processes (Thomas, FitzGibbon & Raymond, 2015)

This is an adult psychophysics study, not a developmental or occlusion-based one, but it is the clearest piece of evidence this pull turned up on GFLAG-0309 disposition (b)'s third open question: does attachment/motivational salience extend persistence GENERALLY, as a weighting applied to any token, or is the person-permanence effect category-specific? Sixteen participants first learned that particular colors reliably predicted monetary gain, loss, or nothing, in a task with no working-memory component at all. They then performed an unrelated visual working-memory task -- remember four faces, each tinted with one of the previously learned colors, across a brief delay, then judge whether a test face matches. The color-to-value association was completely task-irrelevant to the memory judgment. Even so, memory discrimination for a face's identity was reliably better when its color had predicted a gain and reliably worse when it had predicted a loss, relative to neutral -- and critically, eye-tracking during encoding showed no difference in how much visual attention gain-, loss-, and neutral-tagged items received. The authors' reading, and the one this entry leans on, is that the effect sits in the MAINTENANCE phase: value did not get the item into memory more strongly, it changed how well the representation survived once encoded.

The architectural shape of that finding maps unusually cleanly onto what SD-039 does. SD-039 attaches a wanting_strength / arousal_tag payload to a hippocampal anchor at write or invalidation time and preserves that payload across mark_inactive specifically so an inactive anchor remains distinguishable from a generic stale trace -- a motivational tag that is supposed to change how a token's trace survives once it is no longer being actively maintained by attention. Thomas et al. show, in a completely different system (adult visual working memory, not hippocampal anchors; monetary reward learning, not intrinsic wanting/arousal), that a token-specific value tag can do exactly that kind of work: change post-encoding survival without changing initial encoding strength, and stay specific to the tagged token rather than spilling over onto everything else held in memory at the time. If this generalizes, it argues for the token-general reading of the disposition-b working hypothesis -- person-permanence = token persistence (an ARC-080-style object-file) times motivational weighting, where the weighting machinery itself has no built-in person-detector and would extend the persistence of any sufficiently value-tagged token, animate or not.

That "if this generalizes" is doing real work, and honesty requires flagging exactly how far it is being stretched. This is healthy human adults, not infants; the value is explicitly trained and symbolic (a color predicts points), not intrinsic motivational salience of the kind a caregiver or a threat carries; the memory system under test is a short-interval visual working-memory array, not occlusion-spanning search or hippocampal anchor persistence; and the outcome measure is change-detection accuracy, not search behavior after a delay. None of SD-039's actual inputs (ResidueField valence, amygdala-analog arousal tags) have been shown to behave like a learned monetary-value tag. This entry should be read as evidence that the GENERAL PRINCIPLE -- a token-specific value signal can selectively extend a representation's survival independent of encoding strength -- is real and demonstrated with good methodological control (eye-tracking rules out the obvious encoding confound), not as evidence that SD-039's specific implementation does this, or that person-permanence specifically works this way. It is a plausibility argument for the token-general reading, not a test of it.

I could not find a developmental or occlusion-based analog of this finding within this pull's time budget -- the two most on-point developmental papers for the person-specific-versus-general question, Bigelow, MacDonald & MacDonald (1995, Merrill-Palmer Quarterly, a direct mother-versus-unfamiliar-person-versus-object three-way comparison) and Legerstee (1994, British Journal of Developmental Psychology, on familiarity and sound in person-versus-object permanence), are both pre-open-access-era journal articles not available through PubMed/PMC, arXiv, or the web search tools available here. Their titles are exactly on point for disposition (b)'s category-versus-weighting question and they should be the first target of any follow-on pull with institutional library access.
