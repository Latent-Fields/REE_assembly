# Permutation Tests for Studying Classifier Performance (Ojala & Garriga, 2010)

If Combrisson & Jerbi tell Q-092 *that* it needs a permutation null, this paper tells it *which* null -- and in doing so surfaces a gap in Q-092's current design that I think is worth acting on.

Ojala and Garriga develop permutation-based p-values for classifier performance around two distinct tests, with two distinct null hypotheses. The first permutes **class labels**: it estimates a null distribution for whether the classifier found real class structure in the data at all. This is the standard test, and it is the one Q-092 specifies. The second permutes **features within classes** -- a restricted randomisation borrowed from classical experimental statistics -- and estimates a null for whether the classifier is exploiting the *dependency between features*, as opposed to riding the features' marginal distributions.

That second test is directly relevant to Q-092 and currently unspecified in it. Read Q-092's own wording: it asks whether a classifier over "a multivariate trajectory-segment feature signature (refuge occupancy, excursion structure, hazard relationships, transitions, spatial distribution)" detects context-sensitive behavioural differentiation. The word doing the work is *multivariate*. But a label-permutation test cannot distinguish a classifier that has learned genuine joint structure across those five feature families from one that is riding a single dominant marginal -- most plausibly refuge occupancy, which is precisely the feature a reef-presence manipulation would move most directly and most trivially. Both classifiers clear the label-permutation null with the same p-value. Only the within-class feature permutation separates them.

Why this matters beyond tidiness: Q-092 is explicitly a *measurement-layer* claim whose purpose is to test whether this methodology "detects structure that the existing behavioral_diversity_acceptance_criteria.md Rung-2 test does not test for". If the entire discriminability signal turns out to be carried by refuge occupancy, then Q-092's classifier has detected something a univariate refuge-occupancy comparison would also have detected, and the answer to the claim's actual question -- does the multivariate umpire add anything -- is no, even though the permutation test passed. That is a live and unflagged way for Q-092 to return a technically-correct PASS that does not support the conclusion it will be read as supporting. Adding the feature-permutation test converts that from an unexamined assumption into a reported number, at essentially zero extra compute (it is another permutation loop over the same fitted pipeline).

I want to be careful not to overstate what this paper settles. It is a general ML methodology paper -- synthetic and computational-biology datasets, classifier-agnostic, no ecological or RL content. It constrains how Q-092 should be analysed and says nothing whatever about whether the reef phenotype exists or whether SD-054 will produce non-degenerate feature vectors. Nor does it touch Q-092's matched untrained-policy guard: that guard addresses a *confound* (the environments differ geometrically regardless of policy), which is not a null-hypothesis-selection problem and is not what permutation testing is for. And it sits entirely within what Q-092's notes call Stage 1 (discriminability); the claim's insistence that Stage 2 feature-importance interpretation stay separate, and still requires the existing FP taxonomy, is untouched and should stay untouched.
