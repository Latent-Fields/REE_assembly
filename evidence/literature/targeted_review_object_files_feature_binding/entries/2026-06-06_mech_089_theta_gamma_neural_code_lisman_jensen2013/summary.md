# The theta-gamma neural code (Lisman & Jensen 2013) — where "both mechanisms multiply capacity" gets its number

**Paper.** John Lisman & Ole Jensen, *The Theta-Gamma Neural Code*, Neuron 77(6):1002–1016, 2013. The mature statement of an idea Lisman and Idiart proposed in 1995. The claim is that the brain multiplexes discrete items in time using two nested rhythms: each item is carried by a gamma subcycle, and a run of gamma subcycles is packed into one slower theta cycle, with the *order* of items read off their gamma phase within the theta window. Segmentation (which gamma cycle = which item) and sequence (phase = position) fall out of the same code, and the capacity — how many items you can hold at once — is just how many gamma cycles fit in a theta cycle, which lands around the famous 7±2.

**Why it belongs here, and why it answers the capacity question directly.** The object-binding design fork (this directory's parent memo) turns on a question the user posed sharply: if the brain uses *both* slot-like addressing and synchrony-like binding, where does the *advantage in representational capacity* come from? This paper is the answer with a number attached. Slots give you K addressable objects — a fixed, spatial capacity. Phase multiplexing adds an orthogonal temporal dimension: within the same population you can carry several items per theta cycle and encode their relations by phase. Effective capacity becomes roughly (items) × (phase bins), not just (items). That is precisely "both, multiplied," and it is the formal backbone of the claim that coherence/synchrony and slots are complementary rather than competing.

**REE mapping.** This is near-direct grounding for **MECH-089** — the claim that theta-gamma nesting packages E1 updates into theta-cycle summaries that E3 reads (E3 never sees raw E1). MECH-089 *is* a theta-gamma code; Lisman & Jensen is its biological warrant, which it largely lacked before. It also feeds ARC-080: the multiplexing scheme is the mechanism by which a future slot layer would have its capacity extended by REE's existing heartbeat. So this entry sits at the hinge between the synchrony layer REE already built (the heartbeat) and the slot layer it has not — it explains what the heartbeat would *do for* slots once slots exist.

**The honest seam.** Multiplexing presupposes discrete items to assign to gamma subcycles. With no slot/token layer — REE's current state — there is nothing to multiplex, and the phase code carries nothing. That is the same lesson the V3-EXQ-641a null taught from the other direction: REE built the temporal/phase machinery before the addressable items it is supposed to organize. So this paper grounds the *capacity benefit of "both"* while making explicit that the benefit is unrealizable until the slot layer is built. And the capacity it offers is an extension, not an escape — the ~7±2 ceiling is still a ceiling. Evidence base is rodent hippocampal/cortical phase coding plus human EEG/MEG; transfer to REE's engineered heartbeat is bounded but real, so confidence sits at 0.74: high source quality, strong fidelity to MECH-089, moderate fidelity for the ARC-080 capacity-extension claim.
