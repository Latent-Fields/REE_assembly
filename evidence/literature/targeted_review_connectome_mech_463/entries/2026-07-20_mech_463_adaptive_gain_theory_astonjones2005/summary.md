# Aston-Jones & Cohen (2005) -- adaptive gain theory as the canonical global-scalar account

According to PubMed, this is the review that consolidated the locus coeruleus-norepinephrine system into a single functional theory: LC neurons run in a phasic mode (tight, task-locked bursts, associated with exploitation of the current task) and a tonic mode (elevated baseline firing, associated with disengagement and exploration), with ACC and OFC supplying the utility signals that select between them. The mechanism proposed throughout is *gain* -- a multiplicative term that steepens or flattens the response function of target units. [DOI](https://doi.org/10.1146/annurev.neuro.28.061604.135709)

The reason this belongs against MECH-463 is structural rather than empirical. AGT's gain is exactly the kind of object MECH-463 is about: one scalar, applied uniformly, carrying no per-candidate index. Fifty years of noradrenergic physiology has not produced a version of it that is addressed to a particular option among several. So the biology does appear to have built the thing MECH-463 says REE has built three times over (the D1/D2 tanh gain, the harm-urgency threshold shrinkage, the softmax temperature) -- which is at least mild reassurance that the REE substrate is not idiosyncratic here.

But the paper cuts both ways, and I want to be careful not to over-read it. AGT's headline claim is that this scalar produces a *behavioural mode change* -- animals stop exploiting and start exploring. Read naively that says a global scalar can change what an agent does, which sounds like a refutation of MECH-463's argmax-invariance half. I do not think it is, but the reason matters: a temperature change cannot re-rank a score vector, yet it very much changes which action gets *sampled* from that vector. The ordering is invariant; the draw is not. MECH-463 is only coherent if it is making the first claim and not the second, and this paper is a good reminder that the distinction is doing the entire load-bearing job. Nothing in AGT itself makes that distinction, so it cannot be cited as evidence for argmax invariance -- only as evidence that a scalar with no per-candidate structure is the biologically attested design.

The mapping has a second, sharper limit. AGT's gain is the slope of a sigmoid on unit activation. REE's temperature is a divisor on a softmax over K candidate scores. Those are cousins, not the same operator, and the argmax-invariance proof is exact only for the latter. Anyone reaching for this paper as a formal warrant should stop at "biologically motivated", not "mathematically licensed".

I have put this at 0.62 -- high source quality (this is about as canonical as neuromodulation reviews get) pulled down hard by mapping fidelity. What it genuinely cannot do is arbitrate MECH-463's actual falsifier, which is a *variance decomposition* conditioned on arousal decile. AGT has nothing to say about the covariance between the scalar channel and the per-candidate channel, and that covariance is the whole question. This paper sets the frame; it does not settle it. Notably it also does not distinguish MECH-463 from MECH-359 -- both read comfortably onto AGT, which is precisely why the two claims need the experiment rather than more reading.
