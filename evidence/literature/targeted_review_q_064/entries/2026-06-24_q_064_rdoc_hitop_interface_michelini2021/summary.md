# Michelini, Palumbo, DeYoung, Latzman & Kotov (2021) — Linking RDoC and HiTOP

*According to PubMed.* Michelini G, Palumbo IM, DeYoung CG, Latzman RD, Kotov R, *Clinical Psychology Review* 86:102025, 2021. [DOI](https://doi.org/10.1016/j.cpr.2021.102025)

## What the paper did

Two major dimensional frameworks have grown up alongside categorical DSM nosology. RDoC (Research Domain Criteria) is a *neuroscience-rooted* framework that organizes psychopathology around transdiagnostic *biobehavioral systems* — negative valence, positive valence, cognitive systems, and so on. HiTOP is a *symptom-derived* dimensional taxonomy built from the observed covariation of symptoms and maladaptive traits. This paper argues their strengths are complementary and constructs a comprehensive, narrative-review-based mapping between RDoC constructs/subconstructs and HiTOP spectra/subfactors, toward an eventual "unified, dimensional, and biobehaviorally-grounded psychiatric nosology."

## Key findings relevant to Q-064

The HiTOP meta-analysis (Ringwald 2021, also in this review folder) answers Q-064's *registry-economy* question — can syndromes live in a low-dimensional axis space. This paper answers the part that one leaves open: Q-064's **predisposition/expression factoring** requirement. The claim insists that a vector representation must keep "which axes are fragile" (axis-predisposition) separable from "which failure mode is currently expressed" (axis-expression, gated by developmental timing / plasticity / environment), and is only preferred if "the same predisposition vector can yield different expressed syndromes under different developmental/plasticity gating (genetic-risk ≠ inevitability)."

The RDoC↔HiTOP interface is the field's working instance of exactly that two-layer split. RDoC's biobehavioral systems are the *mechanistic/vulnerability* layer; HiTOP's symptom spectra are the *expressed* layer; and the explicit project of the paper is to map one onto the other while keeping them conceptually distinct (RDoC explains, HiTOP measures). This is precisely the architecture Q-064 proposes for REE — ARC-086 vulnerability axes underneath, expressed syndrome positions on top, with the mapping gated by REE's developmental/plasticity machinery.

## How it maps to REE

If REE adopts Q-064's vector representation, this paper supplies the design template: a two-layer encoding in which a mechanistic vulnerability vector (ARC-086 axes ≈ RDoC systems) is distinct from the expressed symptom position (≈ HiTOP spectra), connected by a many-to-many mapping. The "genetic-risk ≠ inevitability" requirement is honoured because the same RDoC-level system profile can, under different gating, surface at different HiTOP-level positions — fragility is not destiny. This is strong support for the *form* of the two-layer vector and for the claim that predisposition and expression should be represented as separate quantities rather than collapsed into one.

## Limitations and caveats

This is a *proposed interface*, not a demonstration that the two layers are empirically dissociable. The mapping between RDoC systems and HiTOP dimensions is explicitly **many-to-many and incomplete**: one biobehavioral system loads several symptom dimensions and vice versa. For Q-064 this cuts two ways. It vindicates the *pleiotropy* premise — one mechanism loading multiple axes is the normal case, not an edge case — but it also means a clean one-mechanism-one-axis vulnerability vector is not on offer, so REE's registry design must absorb dense cross-loading. And the authors concede that not every dimension yet has validated biobehavioral grounding, which echoes Q-064's hard non-degeneracy precondition: REE cannot assume an ARC-086 axis is mechanistically real just because a corresponding symptom dimension exists. So this paper licenses the two-layer design without guaranteeing it will succeed; the dissociability of predisposition from expression in REE remains something a V4/V5 experiment must show, not assume.
