# Network controllability mediates the relationship between rigid structure and flexible dynamics (Gu, Fotiadis, Parkes, Xia, Gur, Gur, Roalf, Satterthwaite & Bassett, 2022, *Network Neuroscience*)

This one is included deliberately as a check on the claustrum-specific literature above, not to pile on more claustrum evidence but to ask a broader question the source thought's target #7 raises explicitly: is "network topology control" a real, formally distinct category from "scalar neuromodulatory control" at all, independent of whether the claustrum specifically is the mechanism? Network control theory -- the framework this paper applies -- gives a mathematically precise way to ask exactly that. Given a fixed structural connectome, control theory can quantify which nodes are positioned to steer the system toward a wide diversity of functional states (their "controllability") versus nodes that can only nudge the system along a narrow set of trajectories. In a large developmental cohort (n=823, ages 8-23), the authors show that regions with higher "boundary controllability" -- structural links spanning multiple cognitive systems, sitting at module boundaries -- have functional connectivity patterns that are measurably more flexible over time, and this flexibility increases with age.

Read generously, this is good news for SD-091's core architectural claim: it demonstrates, independent of the claustrum literature entirely, that "which functional connections are currently active" is a real, quantifiable, and behaviorally-relevant dimension of brain function that is distinct from connection strength or gain. That is exactly the parameter-vs-topology bifurcation SD-091 asserts REE's control plane needs. It is honest, though, to flag that this paper is evidence for a DIFFERENT mechanism than the one MECH-481 proposes, and I think it is worth taking that difference seriously rather than filing it away as "more support." Gu et al.'s account is that topological flexibility is an emergent property of a region's structural embedding -- its position in the connectome graph -- not something actively "instantiated" by an upstream classifier that decides which coalition template applies. There is no analogue here of MECH-481's control-demand-formation step, no discrete triggering event, no typed taxonomy. If REE's actual computational need turns out to be closer to "make certain hub-like modules more topologically flexible by design" than to "build a discrete coalition-instantiation module that gets told which of ten demand types just fired," this paper is the citation for the former, and it would suggest MECH-481, as currently specified, may be over-architected relative to what a network-control-theoretic implementation would actually require.

I've marked this "mixed" rather than "supports" for that reason -- it is real support for the general principle SD-091 needs, but a genuine complication, not a corroboration, of MECH-481's specific discrete-instantiation mechanism. Worth reading before /implement-substrate work starts, precisely because it names a leaner alternative architecture that a REE engineer might otherwise not consider.

Confidence: 0.55. Source quality is high (large cohort, rigorous formal framework, leading group). Mapping fidelity is held to 0.4 because the paper's question (developmental structure-function coupling) and REE's question (task-triggered, demand-typed coalition instantiation) are genuinely different problems that happen to share vocabulary.
