# Domain-General and Domain-Specific Patterns of Activity Supporting Metacognition in Human Prefrontal Cortex (Morales, Lau & Fleming, 2018, *Journal of Neuroscience*)

MECH-481's whole architectural bet is that "typed discrepancy -> control demand -> coalition template" is a better model than "confidence signal -> generic reflection." That bet only makes sense if the underlying metacognitive monitoring signal itself carries information about WHAT KIND of discrepancy is present, not just HOW MUCH. This paper is a fairly direct test of exactly that question, in the narrowest sense the literature currently allows: is confidence about perception represented the same way as confidence about memory, or differently?

The authors had participants make matched-difficulty confidence judgments in a perceptual task and a memory task, then used multivoxel pattern analysis to ask whether the same neural code carried confidence information in both domains. The answer is genuinely mixed, which is the honest and useful outcome here. Anterior prefrontal cortex carries a domain-SPECIFIC code -- decoding confidence in one domain from a classifier trained on the other domain does not transfer cleanly. But at the same time, a separate, widespread frontal and posterior midline network carries a domain-GENERAL confidence and accuracy signal that does not discriminate between the two tasks.

For MECH-481, I think this cuts in a useful direction that resists an easy read. On one hand, it is real evidence that "typed" monitoring signals exist in the brain -- REE's premise that different discrepancy types are not automatically collapsed into one undifferentiated confidence scalar has a genuine neural correlate, at least for the perception/memory distinction. On the other hand, it also shows that a domain-general component persists alongside the domain-specific one, which means a REE implementation that routes ONLY through discrete typed channels, with no generic fallback, may not match the biology -- the brain seems to be running both a generic and a specific signal in parallel, not choosing one or the other. Worth flagging as something the /implement-substrate design should keep in mind rather than treating typing as an all-or-nothing dichotomy.

The bigger limitation, and the reason confidence is not higher, is grain size. This paper distinguishes exactly two domains. MECH-481 proposes something like ten distinct control-demand types (SENSORY_RESAMPLE, PROVENANCE_CHECK, COUNTERFACTUAL_EXPANSION, CROSS_HORIZON_RECONCILIATION, SOCIAL_MODEL_CHECK, and so on). This paper cannot speak at all to whether that finer taxonomy has any neural counterpart -- it would be a significant overstatement to read "perception and memory confidence are separately coded" as "ten distinct discrepancy types are separately coded." It also only addresses the MONITOR and CLASSIFY steps of MECH-481's proposed sequence (deriving a typed signal in the first place) and says nothing about the INSTANTIATE step -- whether detecting a domain-specific signal actually causes a different cortical coalition to assemble. That downstream link is the part of MECH-481 this paper cannot touch.

Confidence: 0.6. High source quality (rigorous MVPA, matched difficulty, well-cited group), but mapping_fidelity held to moderate because the paper speaks only to the upstream half of MECH-481's proposed mechanism, and at a much coarser typing grain than the claim actually needs.
