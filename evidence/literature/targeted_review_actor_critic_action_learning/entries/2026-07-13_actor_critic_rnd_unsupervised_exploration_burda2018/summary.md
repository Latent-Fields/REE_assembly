# Exploration by Random Network Distillation (Burda et al., 2019) — MECH-457

## What the paper did

Burda, Edwards, Storkey & Klimov introduced Random Network Distillation (RND): a fixed, randomly-initialised target network maps each observation to a feature vector, and a second predictor network is trained online to match it. The predictor's error is large on states unlike those it has been trained on, so that error serves as a novelty-scaled intrinsic reward. Bolted onto a PPO actor-critic (with a small trick to combine episodic extrinsic and non-episodic intrinsic returns via two value heads), RND was the first method to exceed average *human* performance on Montezuma's Revenge — the canonical hard-exploration, sparse-reward Atari game — **without demonstrations and without access to the underlying emulator state**, occasionally completing the first level.

## Why it is relevant to MECH-457

The combined 747/748/749 autopsy leaves exactly one live discrimination on the algorithm axis: is an *expert teacher necessary* to make REE's actor-critic substrate learn to forage, or is vanilla policy-gradient exploration simply too weak — would a stronger *unsupervised* explorer clear the 1.0 floor without an oracle to clone? RND is the strongest existence proof on the "unsupervised exploration can be enough" side. It says: a dedicated RL policy (precisely the object MECH-457 argues REE lacks) plus a good exploration signal can bootstrap competent control from sparse reward alone, so behavior-cloning is not the *only* route through the exploration/credit-assignment bottleneck the autopsy discriminated. That directly informs the build decision — it keeps "build a better explorer" alive as a candidate target and gives the deferred H-optim leg a concrete prior (intrinsic-motivation bonus on top of the existing actor-critic).

## The mapping, and where it strains

The honest caveat is scale. RND's Montezuma result rode on hundreds of parallel environments and on the order of one-to-two billion frames. That is a categorically different regime from REE's per-arm budget at D3 forage. "An unsupervised explorer *can* solve hard sparse-reward" (true, at Atari scale) is not "an unsupervised explorer *will* solve REE's env in-budget" (unknown — this is what the H-optim leg must measure). The paper narrows the question rather than answering it: it removes "unsupervised exploration is hopeless here" as a defensible prior, but it cannot substitute for running the leg. There is also a within-paper limit worth carrying: on Pitfall! RND still scored roughly zero, so some sparse-reward geometries defeat even a strong novelty bonus — a reminder that a null on the H-optim leg would not by itself be surprising or decisive against the substrate.
