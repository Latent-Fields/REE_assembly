# Gamma Synchronization between V1 and V4 Improves Behavioral Performance (Rohenkohl, Bosman & Fries 2018)

This study recorded local field potentials from chronic electrode arrays in visual areas V1 and V4
in two macaques performing a covert-attention, stimulus-change-detection task. The headline result:
gamma-band synchronization between V1 and V4 immediately preceding a to-be-detected stimulus change
partly predicted the monkey's subsequent reaction time. Critically, the effect was not just "more
synchrony, faster RT" -- it was phase-specific. As the relative phase relationship between the two
areas' gamma rhythms deviated from its typical, apparently optimal offset, reaction times slowed by
13-31 ms. The effect held only for the attended stimulus representation and could not be explained
by either area's local activity in isolation, pointing to the inter-areal RELATIVE PHASE
relationship itself, not merely bulk synchrony magnitude, as the behaviorally consequential
variable.

**Why this matters for MECH-499.** MECH-499's title explicitly lists relative phase as one of the
population-level dimensions the ephaptic/oscillatory aggregate should be read as (amplitude, phase,
relative phase, frequency, synchrony, cross-frequency relationships) -- deliberately not a single
scalar. This paper is the clearest primate electrophysiology found in this pull that relative phase
between two oscillating populations is a real, independently measurable, behaviorally consequential
variable, separable from synchrony strength. That is direct support for the mechanism-SHAPE MECH-499
requires: if relative phase carried no independent information, the multi-dimensional readout
MECH-499 proposes would be unmotivated.

**What it does not show.** The function tested here is communication EFFICIENCY between two named
visual areas -- optimal phase alignment speeds transmission of an existing signal, sub-optimal
alignment slows it. That is not the same claim as MECH-499's, which is that the field-level pattern
across many concurrent streams SYNTHESISES a new composite "actionable now" state that seeds
hippocampal proposal generation. The circuit (V1-V4, visual attention) and species/task context are
also far from the hippocampal CA1/CA3 theta/SWR regime MECH-499 targets, and the relationship is
correlational (phase-RT covariance across trials), not a causal phase-clamping manipulation.

**Confidence.** 0.62. Solid primate data from a well-controlled, well-cited research programme
(source_quality 0.82), but moderate mapping_fidelity: it validates a necessary ingredient (relative
phase is a real, separable, functionally consequential variable) without testing the actual function
MECH-499 proposes (multi-stream content aggregation into a proposer-anchoring composite state).
