# Continuous Homeostatic Reinforcement Learning for Self-Regulated Autonomous Agents -- Laurencon, Segerie, Lussange & Gutkin (2021, arXiv preprint)

Homeostatically-regulated reinforcement learning (HRRL) is an older idea -- define an agent's reward as a function of its own internal physiological state rather than as an external task signal -- but prior formulations were stuck in discrete time, which is a poor fit for anything meant to model continuous biological regulation. This paper's contribution is to extend HRRL to continuous time and continuous state/action space: the agent carries an internal-state vector (drive variables loosely modelled on things like hunger or thirst) that evolves continuously as a function of its own dynamics and the agent's actions, the agent is required to keep acting to hold this state within a viable range, and reward is derived directly from how that internal state changes. Self-regulation is not a side effect of pursuing external reward here; it is the reward.

This is included in the pull specifically because it is the cleanest available WORKING EXAMPLE of the architectural pattern that this session's brief flags as currently missing in V3: a maintained internal/self-state that is read directly by the valuation mechanism, rather than being computed and then left with nowhere to go. z_self currently has zero reach into E3 selection in the V3 agent (GFLAG-0481) -- DR-10's self-viability penalty is gated on but has no internal producer, and GatedPolicy's direct consumption of z_self is rank-invariant at the default operating point. This paper shows, in an implemented agent, what the alternative looks like: reward literally IS a function of the trajectory of a continuously-updated internal state, so an agent whose internal-state update were frozen while its last value was held constant would lose the very signal that couples behaviour to self-regulation. That is a close computational analogue of INV-069's arm (b) prediction -- that a frozen maintenance process should produce behavioural/coherence drift even though the represented state is untouched -- though the paper itself never runs that specific ablation.

The limits of the mapping are real and worth stating plainly. The "self" in this paper is a small, hand-specified set of physiological deficit variables with a known viable range, not a learned, high-dimensional latent with anything resembling z_self's coherence or identity semantics; V_self's precision/coupling-weighted aggregation over self-tagged latents has no analogue here. The paper also does not itself test the process-versus-representation dissociation INV-069 needs -- it establishes the prerequisite pattern (continuous state feeds reward) without running a frozen-vs-live comparison. And it is, as of this pull, an arXiv preprint with no subsequent peer-reviewed publication found, which caps how much weight the source quality can bear on its own.

Confidence is 0.60. This entry earns unusually high mapping fidelity specifically on the valuation-consumer structure this review was asked to flag, which is why it clears the bar for inclusion despite being a preprint with a much simpler internal-state representation than z_self; it should be read as illustrating what a genuine consumer architecture would need to look like, not as evidence that REE's specific z_self mechanism behaves this way.
