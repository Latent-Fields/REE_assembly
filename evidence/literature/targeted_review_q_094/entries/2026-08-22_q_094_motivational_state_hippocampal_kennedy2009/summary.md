# Motivational state activates distinct hippocampal representations -- Q-094

Of the papers in this pull, this is the one that most nearly answers the question Q-094 actually asks. Kennedy and Shapiro recorded unit activity from the same hippocampal population while rats ran identical tasks under two internal states -- food deprivation and water deprivation. The scene is held constant; the internal state is what varies. That is the matched-`z_world`, differing-`z_self` comparison Q-094 specifies, run in the biology.

Three findings, and they map onto Q-094 almost line for line. First, hippocampal coding was most strongly influenced by motivational state during hippocampus-dependent contextual memory retrieval -- precisely when motivational cues were needed to select among remembered goal-directed actions *in the same places*. Second, the same populations were relatively unaffected during hippocampus-independent random foraging, when hunger and thirst were incidental to what the animal had to do; the authors' own phrasing is that deprivation-derived signals **informed, but did not determine**, hippocampal coding. Third, prospective coding during contextual retrieval was driven by deprivation state and the associated non-spatial target rather than by allocentric trajectory.

The first finding supports the inclusion pole of Q-094 for the bodily/interoceptive variable specifically, which the splitter-cell literature does not reach -- Wood et al. exercise goal identity only. But the second finding is the one I think is genuinely worth carrying into governance, because it is not one of the two options Q-094 currently offers. Q-094's `what_would_answer` sets up a binary: resolve toward INCLUSION if the augmented query discriminates and the `z_world`-only query cannot, or toward MECH-150's existing decision if the augmented query adds nothing or degrades retrieval by making context over-sensitive to internal fluctuation. Kennedy and Shapiro suggest a third shape. Internal state enters the context computation **conditionally on task demand** -- strongly where it disambiguates action selection in a shared place, weakly where it is incidental. Translated into REE that is a relevance-gated or demand-weighted query composition rather than an unconditional `[z_self, z_world]` concatenation, and it is a design that would sidestep the destabilisation cost by construction rather than by hoping the cost is small. I would want that added to Q-094's answer space before the substrate comparison is designed, because a two-arm experiment comparing `z_world` against `[z_self, z_world]` cannot detect it.

Now the boundary, and it is a real one. Hunger and thirst as manipulated here are **discrete, sustained** deprivation states, held across blocks. Q-094's destabilisation worry is about a **continuously-varying** interoceptive signal -- the concern that bodily state never sits still long enough for a context variable built on it to be exploitable. This paper does not test that regime, and it must not be cited as having retired the risk. It supports inclusion under a favourable manipulation; the hard case is untouched.

A second bound: the gating is inferred from a between-task contrast, not from a relevance manipulation within one task. So the mechanism producing the gate is unidentified, and a competing reading is available -- internal state may exert a weaker but constant influence that only becomes detectable when task demand amplifies its behavioural consequences. That is a different architecture from an actual gate, and this design cannot separate them. The third option I described above is therefore a hypothesis worth building, not a policy to copy.

And as with everything in this directory: Q-094's non-degeneracy precondition still stands unaddressed by any of this. MECH-153 records ContextMemory cosine similarity near 1.0 in the absence of a supervised context objective, and two query compositions over an undifferentiated bank are indistinguishable by construction. Literature can raise the prior that this comparison is worth running. It cannot make it meaningful.
