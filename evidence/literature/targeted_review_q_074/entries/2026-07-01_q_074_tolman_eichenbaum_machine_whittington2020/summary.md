# Tolman-Eichenbaum Machine: structural generalization from a factorized map (Whittington et al. 2020)

**Claim tested:** Q-074 -- Is analogy a separate V6 alignment operator (MECH-421), or does it fall out of MECH-300 cognitive-map traversal over a shared symbolic map ("same map, different entry points")?

**What the paper did.** Whittington and colleagues built the Tolman-Eichenbaum Machine (TEM), a model in which the relationships between experiences -- the transition rules of a graph -- are *factorized away* from the sensory content that sits on each node. The structural code and the sensory code are learned as separate streams and then conjoined. The striking result is that once a structural code has been learned, it transfers: the model can be dropped into a *new* environment whose objects it has never seen, and, provided that environment shares the same underlying relational structure, it predicts novel transitions correctly. As a bonus, the same factorization reproduces a broad catalogue of hippocampal and entorhinal cell types (grid, place, band, object-vector) and accounts for remapping phenomena. Published in *Cell* 183(5):1249-1263 ([DOI](https://doi.org/10.1016/j.cell.2020.10.024)).

**Why it speaks to Q-074.** Q-074's second horn -- the one it suspects might be true -- is that analogy is not a bespoke operator but a consequence of traversing a shared map from a different starting point. TEM is close to a formal statement of exactly that horn. "Factorize structure from content, then traverse the same structure with new bindings" is, almost word for word, "same map, different entry points." It is the cleanest existence-proof I have found that a system with a *shared, factorized relational substrate* can carry structural knowledge across superficially-different situations without a dedicated analogy module bolted on. If MECH-300's cognitive-map traversal factorizes as TEM does, the parsimony argument for *not* building MECH-421 as a distinct operator gets real teeth.

**Where the mapping strains -- and it does strain.** TEM demonstrates *structural generalization / transfer*, which is a weaker thing than *analogy-making* in the full four-term sense. Solving "cat is to kitten as dog is to ___" requires aligning two separately-encoded relational structures and reading off the correspondence; TEM instead reuses a single learned structure under new sensory bindings. Transfer within one learned abstraction is not the same as mapping between two. So the honest reading is: TEM removes the *necessity* argument for a separate operator (a shared factorized map clearly can generalize structure on its own) but does not close the question, because the explicit cross-domain alignment step that "hard" analogies seem to need is not something TEM is shown to perform. Add to that the usual transfer worry -- this is a hippocampal-entorhinal model, not REE's symbolic stack -- and the correct status is supporting-but-not-decisive.

**Confidence.** I put this at 0.62, weighting mapping fidelity heavily because Q-074 is an architectural decide-whether-to-build question rather than an empirical one. The source is strong (Cell, with both computational and neural validation), the conceptual fit to the "emergent traversal" horn is the best on offer, and the discount is entirely about the structural-transfer-vs-genuine-analogy gap plus the substrate mismatch. Q-074 is explicitly `substrate_conditional` and marked do-not-build-in-V3, so this entry raises literature grounding for the emergence hypothesis without licensing any V3 experiment; it is context for the eventual V6 design fork, not a verdict on it.
