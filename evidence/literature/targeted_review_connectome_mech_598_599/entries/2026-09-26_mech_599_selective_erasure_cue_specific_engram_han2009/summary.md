# Selective erasure of a fear memory (Han et al. 2009)

Claims: MECH-599. Direction: supports. Confidence: 0.60. PMID 19286560, DOI 10.1126/science.1164139.

Han and colleagues in the Josselyn lab showed that a fear memory is held by a sparse set of lateral amygdala neurons, the ones with more CREB, which are preferentially recruited when the memory forms. Killing those neurons after learning erased that memory. Killing the same number of random neurons did not.

For MECH-599 this is good evidence that a conditioned threat prediction can live in a discrete, removable structure, and is not only a diffuse contextual gradient. That is the gap the claim notes identify on REE's threat side. The safety side has a discrete store (SD-051); the threat side has only the residue field and E3 harm evaluation, which are contextual. The biology has the discrete store.

The paper also cuts against part of MECH-599's registration. MECH-599 lists MECH-598 in depends_on, so the cue-specific threat store is supposed to rely on surprise-driven associability for its credit assignment. Here, which neurons join the memory is set by their excitability at the time of learning, a competitive allocation rule with no associability state. So cue-specific threat memory can form without the MECH-598 mechanism. This does not refute MECH-598. It does suggest the depends_on edge should probably be related_claims, or at least that MECH-599 should be testable with MECH-598 off. I have not changed the claim; that is a governance call.

Confidence 0.60.
