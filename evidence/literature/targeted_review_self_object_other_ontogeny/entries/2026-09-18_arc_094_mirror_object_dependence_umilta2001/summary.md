# The object is what makes the self-other mapping fire

This is the cleanest mechanistic evidence I found that an object stage between self and other is a real computational stage rather than a descriptive convenience.

Umilta and colleagues recorded F5 mirror neurons in macaques across four conditions: a visible grasp of an object, a mimed grasp with no object, and each of those again with the decisive moment -- the hand meeting the object -- hidden behind a screen. The manipulation that matters is what the monkey was shown at the start of each hidden trial. Shown that an object sat behind the screen, the neurons discharged when the hand disappeared behind it, exactly as they did for the fully visible grasp. Shown that nothing was there, the same neurons stayed quiet in the face of identical visible kinematics. Mimed actions did not drive them either.

So the response is not to the movement. It is to an inferable goal, and the object is what supplies it. Remove the object and the mapping from observed action to the observer's own motor repertoire simply does not happen.

For ARC-094 this reads directly onto the object stage. The obvious architectural shortcut -- map self to other via bodily or kinematic correspondence and let the world be scenery -- is precisely the condition in which this circuit is silent. The object is not a third participant the self and other jointly attend to; it is the term that licenses the inference. That gives the object stage a job description, which is more than the claim currently has: supply the goal against which another's behaviour becomes interpretable using one's own apparatus.

Two limits, and they are not small. This is macaque premotor cortex, and it is action understanding, not affect. ARC-094 is a claim about fast empathy. The step from "the action-mirroring mapping is object-dependent" to "the affective pathway is too" is a structural analogy, not a finding, and I do not want it recorded as if it were. It is a reason to look, not a result.

And the object here is a peanut or a cube -- a graspable thing with a motor affordance. That is squarely the cognitive/developmental sense of "object". The object-relations sense, which ARC-094 also intends, has no purchase on this paper at all; that stream is covered by the Gergely and Watson entry in this directory.

**Provenance note.** The four-condition design and the decisive no-object result are not in the PubMed abstract, which says only that neurons fire when the final part of the action is hidden. I verified the object manipulation against the paper's full text on Cell and against Rizzolatti and Craighero's 2004 review, which restates it. Anyone re-checking this entry from the abstract alone will not find it there.

Confidence 0.78. The result itself is about as solid as single-unit work gets; the discount is entirely for the two transfers.
