# Continual Learning Through Synaptic Intelligence (Zenke, Poole & Ganguli, 2017)

Published in the *Proceedings of the 34th ICML* (PMLR 70:3987–3995); open-access mirror at [PMC6944509](https://pmc.ncbi.nlm.nih.gov/articles/PMC6944509/).

**What the paper did.** Synaptic Intelligence (SI) gives each weight an *importance* measure computed entirely online: over training, each parameter accumulates the running sum of how much its own changes contributed to reducing the loss. When a new task arrives, a regulariser penalises modifications to weights that were important for earlier tasks. On permuted MNIST across ten sequential tasks, SI preserves accuracy on Task 1 while learning all ten, comparable to Elastic Weight Consolidation and far better than plain SGD, which forgets catastrophically. On split MNIST across five tasks, networks with synaptic consolidation hold near-perfect accuracy on the initial tasks while naive fine-tuning collapses to chance.

**Why it bears on Q-062.** Q-062 asks whether REE needs an *explicit event-level write-eligible state* (MECH-368) on top of its existing stack, of which MECH-285 (consolidation-priority by V_s residual) and MECH-094 (provenance) are the consolidation members. SI is, essentially, a working model of "consolidation-priority by accumulated importance," and its central result is that this mechanism *alone* — a parameter-level prior, with no gate deciding which events are eligible to write — substantially prevents catastrophic interference. That supports the branch of Q-062 where the existing combination suffices and MECH-368 earns no keep: you can get most of the protection from a continuously-accumulated importance signal that is simply *re-read as a penalty* at update time. It speaks directly to Q-062's sub-question (2): SI behaves like "the salience tag re-read," not like a held intermediate state with its own entry and exit.

**The mapping, honestly bounded.** I score this **supports** but at modest confidence, because it argues for the cheaper hypothesis rather than refuting the expensive one. SI shows consolidation-priority *can* work without an explicit write-eligible state; it does not run the contrast Q-062 actually needs — a substrate *with* a held write-eligible state versus one *without* — so it cannot show the state adds nothing. And the transfer is non-trivial: an importance-weighted regulariser on MNIST-scale task sequences with clean task boundaries is not REE's online, non-stationary world-model/policy stream, where "which task am I in" is never handed to the system. "Substantially prevents forgetting here" is evidence for plausibility, not for sufficiency on REE's path.

**Confidence.** I set this at 0.62. Source quality is solid — SI is a foundational, much-replicated continual-learning method — but it is a conference model on small benchmarks, and its mapping fidelity to the held-state-versus-no-state question is only moderate. Read alongside the Masse PNAS entry, it sharpens the same picture: gating needs a consolidation partner, and the partner that does the work in both papers is a *parameter-importance / consolidation-priority* mechanism, not a separate admission state — which is the MECH-368-not-needed reading. The astrocyte-gating entry supplies the countervailing evidence.
