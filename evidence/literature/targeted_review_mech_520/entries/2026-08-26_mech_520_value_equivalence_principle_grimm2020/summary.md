# Value equivalence: the same theorem, read as a virtue or a hazard (Grimm et al. 2020)

**Source.** Grimm, C., Barreto, A., Singh, S. & Silver, D., *The Value Equivalence Principle for Model-Based Reinforcement Learning*, NeurIPS 33, 2020. [arXiv:2011.03506](https://arxiv.org/abs/2011.03506).

**What the paper does.** The authors formalize "value equivalence" (VE): two environment models are value equivalent with respect to a given set of policies and value functions if they produce identical Bellman updates for every member of that set, regardless of whether the models otherwise resemble the true environment's dynamics. The central theorem is a monotonicity result: as the policy/function set under consideration is progressively enlarged, the class of models satisfying value equivalence for that set shrinks, until in the limit (all policies, all value functions) it collapses to a single point -- a model that perfectly reconstructs the true environment. Conversely, a small policy/function set leaves a large, loosely-constrained space of models that all satisfy VE despite disagreeing about everything the set doesn't care about. The paper offers this as the theoretical grounding for why reconstruction-free, value-shaped models (VPN, value iteration networks, and most prominently MuZero) work as well as they do: they don't need to model the world faithfully, only faithfully enough for the value functions and policies actually in play.

**Why it matters for MECH-520, and why it needs to be read carefully.** MECH-520's own registration names value-equivalent models as external precedent it has not yet verified, and this is the correct paper. What it supplies is more precise than a loose analogy: the VE monotonicity theorem is a formal proof that a NARROW policy/value-function set under-constrains the model, admitting a wide space of solutions that need not preserve anything outside that set's concerns -- which is close to a mathematical restatement of MECH-520's own claim that "a pure value-carving objective admits solutions that discard everything not currently useful." MECH-520's proposed fix -- a cross-horizon predictive obligation -- can be read in this paper's own vocabulary as effectively widening the constraint set beyond the current, narrow value function toward something closer to full predictive sufficiency, which the theorem says is exactly what shrinks the admissible model class back toward the non-degenerate end.

**Why this is marked mixed, not supports.** This citation is genuinely double-edged, and flattening it into simple support would misrepresent the source. Grimm et al.'s own argument is that value-equivalent compression is DESIRABLE: the whole point of the paper is to explain why letting go of full environment fidelity, in favor of compression toward exactly the Bellman-relevant structure, is a virtue that buys efficiency without sacrificing performance -- and to credit MuZero's success to this property. The authors do not themselves argue that value-only compression is dangerous; MECH-520 has to argue that REE's actual value/policy set (a near-scalar wanting projection, per the claim's own framing) sits closer to the degenerate end of this spectrum than to the "enough policies and functions to be safe" end -- a claim about REE's specific situation that the paper's celebratory framing of the general principle does not itself make. It's also worth being precise about scope: the theorem is about preserving VALUE (Bellman-update fidelity) under compression, not directly about REPRESENTATION GEOMETRY collapsing to a low participation ratio the way SD-070 empirically measured (z_world collapsing to ~1.06 at world_dim=128) -- the intuitive link between "fewer preserved Bellman-irrelevant distinctions" and "geometric collapse" is not something this paper formally establishes.

**Confidence.** 0.6. Source quality is high (an influential, rigorously-proved NeurIPS paper from a strong group including members of the MuZero team). Mapping fidelity is moderate, capped by the valence mismatch described above and by the value-vs-geometry scope gap.

**Lit-only verdict, not governance.** Supplies the precise formal machinery behind MECH-520's collapse worry, verified and correctly attributed, but the source paper argues the opposite normative conclusion about the same theorem. This entry should be cited as "formal precedent for the mechanism, contested on the value judgment," not as unqualified external validation -- and any governance pass building on it should keep both halves of that framing intact rather than citing only the supportive half.
