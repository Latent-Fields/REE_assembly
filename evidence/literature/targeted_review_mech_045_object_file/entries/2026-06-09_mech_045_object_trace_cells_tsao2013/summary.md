# Object-trace cells: persistence after the object is gone

Tsao, Moser and Moser (2013) recorded in the lateral entorhinal cortex (LEC) — the "what/content" partner to the medial entorhinal "where" stream — and found neurons that fire near discrete objects, and, more strikingly, a subset that **keep firing at the location where an object used to be after the object has been removed**. They called these *object-trace cells*, and argued they are a cellular correlate of object-place memory. A control point matters here: LEC cells show little spatial modulation in an empty field; their object firing reflects the *history of experience*, not raw stimulus drive.

This is the neural witness for the half of MECH-045 that the cognitive-psychology sources establish only behaviourally: **persistence**. An object file is only worth having if it outlives perceptual contact — if it can hold an entity's state while the entity is occluded, out of view, or gone. Object-trace cells are exactly that signature at the single-cell level: a representation that survives the object's disappearance and continues to report it. Where Kahneman et al. give the function and Pylyshyn gives the label-free key, Tsao et al. give the **persistence-through-absence** that the persistence-vs-ablation experiment is built to test. And because the signal lives in LEC — the content/identity stream — it grounds the *what* side of a token buffer, complementing the *where* side that MEC object-vector cells cover. That what/where split is itself useful to the design: it tells REE that the persistence content and the spatial anchor are biologically separable channels, which is why the memo proposes a token buffer that *holds* features and *consumes* an anchor rather than conflating the two.

The caveats are real and again shape the experiment rather than merely qualifying the claim. First, trace cells code a remembered object **place**: persistence here is still partly anchored to a *location*, not to a label-free token followed *through motion*. A REE buffer that simply remembered an object's last-seen cell would reproduce trace-cell firing while completely failing the harder test — re-identifying the object once it has *moved somewhere new*. That is the precise boundary between persistence-through-absence (which this paper grounds) and token tracking (which it does not), and it is why the experiment's non-vacuity precondition demands re-identification of a *moved* entity, not merely recall of a vacated location. Second, only a small subset of LEC cells show the trace property and the **write rule** for experience-history is unresolved, so the paper licenses "a persistence buffer exists" without prescribing how it updates. Third, the experience-history dependence means genuine identity persistence has to be disentangled from slow sensory adaptation — which is exactly what the ablation/shuffle control arm is for. Confidence 0.72: a clean, on-point persistence signature in the right stream, discounted for the residual location-binding and the unresolved update mechanism.
