# Visual indexes (FINSTs): the label-free KEY MECH-045 needs

If Kahneman et al. give MECH-045 its *function* — a per-object buffer that integrates features across motion — Pylyshyn's visual-index theory gives it the *key*. Pylyshyn (2001, consolidating two decades of FINST work) argues for a **preconceptual** mechanism that individuates and tracks about four or five visual objects by sticking a pointer ("finger of instantiation") to a feature cluster and following it through space and time. The defining property, repeated throughout the paper, is that an index refers to an object **demonstratively** — like saying "this" or "that" — *without encoding the object's identity or any of its properties*. Tracking happens before categorisation, not after it.

That property is the exact phrase in MECH-045 that the live REE stores cannot satisfy: "binding... **without symbolic labels**, keyed by entity **token instance**." The SD-057 `IncentiveTokenBank` keys on a resource *type tag*; the SD-039 ghost-goal bank keys on a spatial *anchor*. Neither individuates *this* moving object as a label-free pointer. FINST theory is the cleanest statement in the literature of what a token KEY is: a reference that survives the object moving, attaches to spatiotemporal continuity rather than to features, and is agnostic to what the object turns out to be. REE's proposed mechanism — data-association over z_world continuity, assigning a persistent token id with no type tag — is the computational instantiation of "stick an index to a feature cluster and follow it."

The multiple-object-tracking paradigm that grew out of this theory is also a gift to the experiment design. MOT is, operationally, exactly the discriminative test MECH-045 needs: present several identical objects (so features cannot disambiguate them), move them, and ask whether the system still knows which is which. That "identical objects, so only continuity can carry identity" structure is what forces a non-vacuous re-identification and rules out the location-collapse failure mode that haunts the object-file benefit.

Three honest caveats, each of which shapes the design rather than just hedging it. First, a FINST is a **bare pointer with no content** — it tracks identity but stores nothing. MECH-045 explicitly wants a per-token *feature buffer* as well, so REE must graft a feature store onto the index; the index theory tells us how to key, not what to hold. Second, the **~4-5 capacity limit** and the collapse of tracking under fast motion or occlusion are real human-vision signatures; a REE buffer with unbounded tokens and no eviction policy would neither reproduce them nor have a principled way to forget. Third, Pylyshyn insists indexing is largely **bottom-up and partly divorced from attention**, which sits in mild tension with ARC-006/MECH-045's "attention-gated" commitment — so the attention coupling REE proposes is a deliberate addition, and I flag it as such in the memo rather than claiming the literature hands it over. Confidence 0.78: a strong, on-point framework for the KEY, discounted because it is a theory-plus-paradigm rather than one decisive experiment and because it grounds only half the claim.
