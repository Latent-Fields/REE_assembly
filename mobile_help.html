REE mobile access

This public helper is intentionally sanitized. Use the ignored local runbook for the real tunnel name, explorer URL, host alias, and user.

The explorer

Open the private explorer URL from docs/mobile_access.local.md after the phone WireGuard tunnel is on. 
<EXPLORER_URL>

Claude Code

  1. Turn on the private WireGuard tunnel named in the local runbook.
  2. Connect with the SSH or mosh alias from the local runbook: 
    mosh <SSH_HOST_ALIAS>
  3. Attach the persistent session: 
    tmux attach -t ree
  4. Start Claude Code: 
    claude
Detach without killing it: press Ctrl-b, then d. Reconnect later and attach the same tmux session.

After a workstation reboot

The helper script can recreate the detached ree tmux session: 
bash scripts/claude_mobile.sh

If something will not connect

Explorer will not loadConfirm the tunnel is on, then check the private URL in the local runbook.
ssh/mosh refusedConfirm workstation SSH is enabled and the phone public key is installed.
mosh hangsFall back to plain SSH using the local runbook alias or address.
Host key promptExpected on first connection after provisioning.

Private provisioning details live in docs/mobile_access.local.md, which is gitignored.
