📱 REE on your iPhone

Both of these ride your WireGuard tunnel. Turn the REE-net tunnel on first.

🌐 The explorer (Safari)

Open in Safari:

http://10.8.0.11:8000/explorer

That's it — no terminal needed for the explorer.

⌨️ Claude Code (Blink)

  1. WireGuard REE-net tunnel on.
  2. In Blink, connect (Face ID unlocks the key): 
    mosh mac
    No host alias set up? Use ssh dgolden@10.8.0.11.
  3. Attach the always-on session: 
    tmux attach -t ree
  4. Start Claude Code: 
    claude
Detach without killing it: press Ctrl-b, then d. Lock the phone, come back later, tmux attach -t ree and you're exactly where you left off.

🔁 After a Mac reboot

Nothing to remember. The explorer (serve.py) re-creates the ree session automatically whenever it starts, so it's always waiting. Just connect with the steps above.

If you ever need it by hand: bash ~/REE_Working/REE_assembly/scripts/claude_mobile.sh

🛠 If something won't connect

Explorer won't loadWireGuard tunnel off, or it lost its handshake — toggle REE-net off/on.
ssh/mosh refusedRemote Login is off on the Mac (System Settings → General → Sharing → Remote Login).
mosh hangsFall back to ssh dgolden@10.8.0.11.
Host key promptFirst connection only — type yes.
