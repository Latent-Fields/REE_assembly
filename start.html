Running experiments

Experiments run on the cloud workers. The scaler powers workers on when the queue (ree-v3/experiment_queue.json) has work, so queueing an experiment with /queue-experiment is normally all that is needed.
The Mac's own V3 runner is off by default. The file ~/.ree_runner_disabled keeps it down; pressing Start in the explorer's Experiments tab clears that file and starts the runner.
ree-v2 is closed. Its past results stay visible in the Experiments tab, but it has no runner or queue controls.
