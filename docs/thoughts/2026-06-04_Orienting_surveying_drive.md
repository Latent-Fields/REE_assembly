Thought intake: orienting/surveying drive as pre-approach active sensing

Date: 2026-06-04
Status: intake / routing hypothesis only. Not an active work item unless the result pattern below appears. Not a change to current REE-v3 acceptance criteria.
Scope: Reflective Ethical Engine version 3 (REE-v3), nursery-to-forager bottleneck, cue-recall-to-contact bridge.

1. Core thought

REE-v3 may be missing a primitive orienting/surveying drive or orienting/surveying mode.

This is distinct from curiosity, cue recall, and approach.

Current suspected sequence:

token formation -> cue recall -> wanting -> approach -> contact

Possible missing sequence:

token formation -> cue recall -> wanting -> orient/survey/sample -> directional gradient improves -> approach -> contact

The organism may need a brief active-sensing phase between “something matters” and “move effectively toward it.”

2. Why this matters now

V3-EXQ-638a has moved the cue-recall failure downstream.

The original 638 failure was cue-silent because the incentive-token bank was empty. 638a fixed token formation: the token bank can populate and cue recall can fire.

However, early 638a readout showed the possible next failure shape:

cue fires, but contact does not lift.

That should not be collapsed immediately into “cue lacks motivational authority.” It may instead mean:

cue recall has made the resource meaningful, but the agent lacks an orienting/surveying behaviour that converts meaning into useful spatial/action information.

In animal terms: the organism may “smell something” but not yet turn, scan, sample, or localise before attempting approach.

3. Distinction from nearby mechanisms

Existing mechanism	Difference from orienting/surveying
MECH-111 curiosity / novelty	Broad information-seeking driven by moderate prediction-error surprise.
SD-057 / MECH-347 cue recall	A perceived cue retrieves wanting or incentive salience.
MECH-295 drive -> liking -> approach	Converts drive and liking into approach tendency.
Attention / precision selection	Weights and selects content for processing/control.
Orienting/surveying	Actively samples the local field before commitment so useful cues, gradients, and affordances become available.

Orienting/surveying is not “wanting” and not “approach.” It is a pre-approach active-sensing mode.

4. Literature-shaped interpretation

The relevant literature does not necessarily define one unified “orienting drive,” but it supports the joint concept:

* Orienting response: organisms interrupt ongoing behaviour and orient toward novel or significant stimuli.
* Active perception / active sensing: perception is generated by action; organisms move eyes, head, body, whiskers, fins, or sensors to improve the available sensory field.
* Curiosity / intrinsic motivation: broad exploratory learning, especially useful when extrinsic rewards are sparse or deceptive.
* Foraging search modes: non-directional cues can signal “search here more carefully” even when they are not precise enough to directly guide approach.

REE interpretation:

A cue may not be an approach vector. It may be a search-mode trigger.

5. Candidate functional definition

Orienting/surveying drive/mode:
A control state entered when a cue/token/need signal is present but directional or affordance confidence is too low for reliable approach.

Its function is to improve action-relevant information by active sampling.

Possible behaviours:

* turn / scan locally;
* sample nearby gradients;
* move in small exploratory arcs;
* increase local heading entropy briefly;
* compare resource-field change across movements;
* delay hard commitment until directional confidence improves;
* switch from broad survey to approach once gradient confidence rises.

6. Possible trigger condition

Enter orienting/surveying mode when:

1. cue recall fires or incentive token is activated;
2. current need/body state makes the cue relevant;
3. no high-confidence approach vector exists;
4. hazard pressure is not high enough to veto surveying;
5. recent contact has not already resolved the need.

Exit orienting/surveying mode when:

* resource gradient confidence rises above threshold;
* approach vector becomes stable;
* hazard risk exceeds threshold;
* cue decays;
* survey budget expires;
* contact occurs.

7. Candidate metrics

If this becomes testable, measure:

* orient_mode_entries_after_cue;
* survey_steps_after_cue;
* heading_entropy_after_cue;
* gradient_information_gain;
* resource_field_peak_delta_after_survey;
* time_from_cue_fire_to_first_directional_approach;
* cue_fire_to_contact_rate;
* hazard_exposure_during_survey;
* survey_budget_expiry_count;
* approach_vector_confidence.

Useful discriminator:

If cue recall fires but contact remains zero, ask whether the agent ever entered an orient/survey mode and whether surveying improved the resource gradient before approach.

8. Relation to 638b and safe weaning

This should not replace the already captured 638b interoceptive-cue design.

It is a possible branch after, or alongside, the Layer-2 cue-authority question.

Routing suggestion:

Result pattern	Interpretation	Next route
Cue does not fire	Token/perception/wiring problem.	Re-audit cue formation.
Cue fires, no contact, no orienting/surveying	Missing pre-approach active-sensing mode.	Consider orient/survey diagnostic.

9. Version 3 containment

Do not expand the REE-v3 green-board path by default.

This is a captured hypothesis for routing future failures, especially if 638a/638b show cue firing without contact lift.

The immediate race remains:

feeding -> protected consolidation -> token formation -> cue recall -> contact lift -> interoceptive authority if needed -> safe weaning -> autonomous foraging.

Orienting/surveying becomes active only if the cue-recall-to-contact bridge fails in the specific pattern:

cue exists, cue fires, but the agent does not gather enough action-relevant information to approach.
