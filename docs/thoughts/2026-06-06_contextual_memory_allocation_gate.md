# Contextual Memory Allocation Gate

**Date:** 2026-06-06
**Source trigger:** de Sousa et al., "The prefrontal cortex controls memory organization in the
hippocampus," *Nature Neuroscience*, 28 April 2026 (vmPFC -> medial entorhinal cortex -> dorsal CA1;
contextual similarity and temporal distance gate whether two memories are linked or kept separate,
especially when separated by days rather than hours).
**User seed:** "This looks very relevant for REE."

---

## The thought (raw)

REE cannot simply accumulate memories. It must decide, for each new experience, whether to
**integrate** it with an existing trace, hold it **separate**, or **partially overlap**. The de Sousa
result is a biological analogue for that decision being an *active, top-down-regulated control problem*,
not a passive store operation.

Candidate framing: a `Contextual Memory Allocation Gate` -- a control-plane-regulated write policy over
the hippocampal graph that regulates trace overlap using context similarity, temporal distance, schema
fit, salience, prediction error, uncertainty, reality-coherence risk, and goal relevance.

Two failure poles bracket the gate:
- **over-integration** -> unrelated traces linked -> false association -> reality-coherence loss
  (the generalisation/delusion boundary).
- **over-separation** -> related traces isolated -> no generalisation -> schema failure / relearning.

Psychiatric extrapolation (psychosis as high-salience + weak separation + low reality-coherence;
rumination as repeated failed partial integration; trauma as affective overbinding) is *translational
speculation from mouse circuit work* -- flagged, not asserted.

## Disposition

NOT promoted canon. **V4/V5 territory; off the V3 critical path.** REE already owns the *gates*
(MECH-094 hypothesis tag, MECH-261 mode-conditioned write gating, ARC-035 vmPFC control); the genuinely
novel piece is the *gating policy / decision algorithm*, which is not present. For V3, at most a
lightweight contamination/overlap check **if** current experiments surface memory contamination,
false-reuse, or overgeneralisation across runs. Full structured analysis + novelty/overlap table +
candidate claims + open questions in the Stage-2 intake linked above.

## Affected components

Control plane (vmPFC / SD-033) -> hippocampal graph (ARC-007) write/allocation; pattern separation
(MECH-147, V4); schema consolidation (MECH-272/273, INV-039, SD-017); write-gating (MECH-094/261);
integration-vs-retrieval distinction (MECH-257, ARC-035).
