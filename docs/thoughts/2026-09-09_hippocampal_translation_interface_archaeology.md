# REE translation-interface archaeology: hippocampal indexing, remapping, and mutual legibility

**Date:** 2026-09-09  
**Status:** archaeology / synthesis; not a claim registration, implementation decision, or experiment-queue mutation  
**Scope:** internal REE genealogy of translation-like mechanisms, with emphasis on hippocampal/path-memory functions and their later convergence with representational-interface work  
**Method:** earliest-currently-evidenced rule. Where repository history was checked, dates refer to the earliest currently evidenced commit carrying the surviving artefact; absence of an earlier surviving artefact is not proof that the idea was never discussed earlier.

## Executive conclusion

The current idea of **translation between specialised representational systems** did not appear in REE as one late, isolated invention. Several partially independent lineages have converged on the same architectural problem:

> A system can preserve useful information while failing because another system cannot interpret, index, retrieve, or use that information in the form required at the relevant moment.

The archaeology does **not** support the simple statement that the hippocampus was always intended as a universal translator. The surviving early REE architecture gives hippocampal-like machinery a narrower and more defensible set of functions:

- path and trajectory indexing;
- chaining action-linked transitions;
- temporal and causal ordering;
- pattern separation and pattern completion;
- replay and counterfactual reconstruction;
- context switching and hypothesis injection;
- provenance support;
- and later viability mapping in action-consequence coordinates.

The explicit idea of **cross-system representational translation** becomes much clearer only in the September 2026 line: Temporary Coordinated Representational Transformations (TCRT), mutual legibility, communication subspaces, receiver-conditioned translation, recurrent interface stability, shared reference frames, and temporal gates.

The strongest synthesis is therefore not:

> `hippocampus = universal translator`

but:

> **hippocampal-like machinery may provide relational indices, temporally ordered correspondences, replayed paired examples, and context reinstatement that allow specialised systems to learn, select, maintain, or re-engage low-complexity translations between their otherwise different representations.**

In that formulation, the hippocampal system can be crucial to translation without having to contain one universal shared latent language or implement every bridge itself.

This also exposes a direct current experimental question. The V3-EXQ-978 -> 1002 -> 1008 -> 1010 lineage asks whether `z_world` contains information that is merely hard for the native consumer to use, or whether the encoder has destroyed the decision-relevant relation. If V3-EXQ-1010 shows that a sufficiently expressive held-out decoder can recover the required action mapping, the archaeology already contains several candidate mechanisms for how such a difficult mapping might become developmentally tractable and later simplified. If 1010 cannot recover it despite adequate decoder fitting, the developmental/translation question moves upstream toward representation formation rather than disappearing.

## 1. Earliest currently evidenced root: maps as paths through consequential state

### 2026-02-08 — residue/path cognitive-map thought

The earliest surviving item found in this archaeology is `2026-02-08_residue_paths_cognitive_map.md`, present in repository history on 2026-02-08.

Its formulation is extremely compressed: residue is treated as a map, while hippocampal structures record the path taken through that map. The important primitive is already **relational and trajectory-based** rather than a static semantic label.

This is not yet a translation theory. It nevertheless establishes an early architectural intuition that later becomes important:

> cognition may require preserving how states are related by traversal, not merely representing states independently.

That distinction matters because a relational map can serve as a reference system between representations even when the representations themselves use different coordinates.

**Archaeological classification:** early conceptual ancestor of relational indexing; not evidence of an explicit cross-representational translator.

## 2. First explicit cross-system handoff: E2 kernel -> hippocampal rollout

### 2026-02-09 — E2/HPC interface

`2026-02-09_e2_hpc_interface.md` is the earliest surviving artefact found here that explicitly defines an **interface between two specialised computational systems**. Repository history currently evidences it on 2026-02-09.

The division is clear:

- E2 supplies short-horizon conditional forward-prediction kernels;
- hippocampal systems chain those kernels into explicit multi-step rollouts;
- E1 constrains the rollouts;
- control-plane variables alter horizon, branching and temperature.

This is already a form of representational handoff, but importantly it is **not described as coordinate translation**. It is closer to a type contract:

`local action-conditioned consequence primitive -> explicit trajectory construction`

The later ARC-018/MECH-033 reframe sharpens this further. The V2 failure is interpreted as the interface existing while **passing the wrong type of object**: sensory-state transitions were not adequate substitutes for action-consequence objects. In other words, an interface can be live and computationally connected yet remain functionally poor because sender and consumer disagree about what kind of relation is being communicated.

That is a direct precursor to the September mutual-legibility distinction between:

`information present`

and

`information expressed in the consumer-relevant geometry/type`.

**Archaeological classification:** direct architectural ancestor of the modern interface problem; not yet a learned translator.

## 3. Provenance and temporal support: correct content is not enough

### 2026-02-09 — Papez-like reality filtering

`2026-02-09_papez_circuit_reality_filtering.md` gives hippocampal trace and temporal ordering a provenance role. Internally generated E1 content should not acquire high commitment precision merely because it is available; hippocampal trace support and temporal ordering help determine whether it should be treated as grounded.

This adds a second early constraint that later translation work rediscovers in different language:

> the usefulness of transmitted content depends on **where it came from and how it is paired with context**, not merely on its vector content.

The September communication-subspace work later makes the analogous experimental demand through correct-pair versus mismatched-pair controls. The receiver-conditioned translation work similarly requires that the receiver state and context actually matter.

The genealogical connection is conceptual rather than a documented direct derivation. There is no evidence in the surviving September thoughts that their pairing controls were explicitly derived from the February Papez note. The similarity should therefore be recorded as **convergence**, not invented ancestry.

**Archaeological classification:** independent early convergence on provenance/pair-specificity.

## 4. The key hippocampal precursor: self-indexed transition relations

### 2026-02-15 — Commit-Indexed Trajectory Module (CITM)

`2026-02-15_commit_indexed_trajectory_module.md`, currently evidenced in repository history on 2026-02-15, is the strongest early ancestor of the present “translation map” intuition.

Its primitive is:

```text
S_pre(t)  = pre-commit predicted state
A(t)      = committed action
S_post(t) = post-commit observed state
Delta(t)  = S_post(t) - S_pre(t)

tau(t) = (S_pre(t), A(t), Delta(t))
```

The important move is that `tau(t)` is described as **self-indexed by construction**. It carries:

- the state before intervention;
- the intervention/action;
- the resulting discrepancy/change;
- directionality;
- causal ownership information.

The proposed hippocampal-like system stores and chains these tuples. Geometry can emerge through compositionality, cycle consistency and metric regularity; time can emerge through ordered chains and replay.

This is highly relevant to cross-representational translation because it supplies something a generic latent bridge otherwise lacks: **a shared relational anchor**.

Two subsystems need not agree on their full coordinates if both can refer to:

- the same intervention;
- the same event boundary;
- the same before/after relation;
- the same trajectory position;
- or the same episode.

In modern interface language, CITM does not necessarily give A and B a common representation. It can give them a common **indexing relation** against which different representations can be aligned.

This is the clearest archaeological bridge between the early hippocampal programme and the September 2026 shared-reference-frame thought.

**Archaeological classification:** strong conceptual ancestor of shared relational reference frames; direct ancestor of current hippocampal-system architecture.

## 5. Learned remapping of the index itself

### 2026-02-15 — hippocampal backward shift / commitment-boundary migration

The sibling `2026-02-15_hippocampal_backward_shift.md` proposes that a learned backward shift in hippocampal activity can be interpreted as migration of the effective commitment/evaluation boundary toward the earliest state at which the future becomes causally constrained.

Whether that biological interpretation ultimately survives is separate from its internal REE role. Architecturally, it introduces an important idea:

> the useful hippocampal index need not remain fixed across development or learning.

The reference point can migrate when the organism discovers a more causally informative relation.

This anticipates two later ideas:

1. **developmental ontology/rebucketing** — learning can change which distinctions organise experience;
2. **temporal gating/reference frames** — the same content can be useful or useless depending on which phase/event boundary it is indexed against.

Again, this is not evidence that the later thoughts were consciously derived from the February note. It is a genuine repeated architectural motif.

**Archaeological classification:** early convergence on learned re-indexing and phase-sensitive relevance.

## 6. Stable hippocampal architecture before the explicit translation turn

The current `docs/architecture/hippocampal_systems.md` preserves and sharpens the February line.

The hippocampal braid is assigned path memory: **indexing, storage and replay of experienced trajectories through latent space**. It is explicitly constrained not to compute value, select actions, overwrite perception or erase residue.

It contains several functions relevant to interface translation without itself being declared a universal translator:

- sparse indexing of decision points and surprising transitions;
- event segmentation;
- pattern separation;
- pattern completion;
- replay of partial/full trajectories;
- routing signals for offline reprojection;
- hypothesis injection into predictive systems;
- counterfactual trajectory construction;
- viability mapping in action-consequence coordinates.

The MECH-033 history is especially important. The earlier E2 -> hippocampus chain failed when E2 supplied the wrong representational object. The architecture now explicitly requires action-consequence objects rather than generic sensory-state transitions.

That is nearly the modern interface problem stated in older vocabulary:

> **a live connection is not sufficient; what crosses the connection must preserve the relational object the receiver's computation requires.**

## 7. Developmental branch: broad connectivity -> structured sparse access

### June 2026 — CA3 developmental pruning

The June architecture line `developmental_pruning_and_sparse_memory_cognifold.md` registers MECH-362 and Q-057 as a V4/V5 developmental compass.

Its relevant pattern is:

```text
early: broad / dense / weakly constrained access
        -> experience + offline selection
mature: sparse / structured / convergent access
```

This branch is not intrinsically about translation. Its relevance is developmental. If cross-system mappings or hippocampal indices begin broad and permissive, maturation may consist partly of discovering which correspondences repeatedly matter and then making those correspondences cheaper, sparser and more reliable.

The September `developmental_overcapacity_pruning_sparse_interfaces` thought independently rediscovered this general motif and extends it from recurrent hippocampal connectivity to **interfaces and transformations**. Its distinctive addition is the same-final-capacity/different-history test and the use of bridge complexity as a developmental variable.

**Archaeological classification:** independent developmental lineage that now converges with interface translation; should amend/extend existing developmental claims rather than duplicate them.

## 8. Representational reorganisation becomes explicit

### 2026-09-03 — Temporary Coordinated Representational Transformations (TCRT)

TCRT is the point where the modern problem becomes explicit:

> information being present in a representation is not the same as information being present in the form required by the current computation.

It proposes a temporary decision-relevant representation:

```text
R_(t,a) = T(S_t, D_t, a)
```

where rich substrate, directive/contextual state and candidate action jointly shape the form that reaches decision machinery.

This is a major conceptual expansion over the early hippocampal work. The transformation is deliberately **distributed and recurrent**, not assigned to one hippocampal module. Goals, threats, rules, uncertainty, context, memory, candidate simulation and other directive structures may all participate.

TCRT therefore prevents an over-reading of the archaeology:

> even if hippocampal indexing is important to translation, TCRT does not imply that the hippocampus performs the whole transformation.

Its likely role is to provide some of the remembered relations, indices, hypotheses and replayed correspondences that participate in a wider recurrent transformation.

**Archaeological classification:** independent conceptual reframing that converges with the earlier interface/type-contract problem and makes “usable form” explicit.

## 9. Replay as representational maintenance rather than mere recall

### 2026-09-04 — Developmental Ontology and Replay

`2026-09-04_developmental_ontology_and_replay.md` argues that development can change the representational scheme itself: categories can split, merge, reweight and acquire different causal meaning. Replay can compare episodes that were not adjacent online and may reorganise earlier experience after later consequences reveal what distinctions mattered.

This provides a possible maintenance mechanism for translation maps.

If system A changes its local representation while system B remains specialised around its own computation, at least three things may need maintenance:

1. the representation in A;
2. the episodic/reference index that says which A states correspond to which events/relations;
3. the interface by which B reads what it needs from A.

The September mutual-legibility work later names the third item explicitly. The hippocampal/replay lineage already had strong machinery for the first two.

**Archaeological classification:** direct replay/representational-reorganisation ancestor; convergence with later interface-maintenance hypothesis.

## 10. Translation becomes an explicit cross-system variable

### 2026-09-07 — Mutual legibility without representational collapse

This thought formalises the cross-system problem directly.

Its central claim is that specialised systems may retain distinct high-dimensional internal representations while coordinating through lower-dimensional, context-sensitive communication subspaces and low-complexity transformations.

It introduces the ladder:

```text
encoded
-> decodable
-> natively accessible
-> bridgeable
-> pairing-specific
-> causally used
-> behaviourally useful
```

and the approximate bridge-complexity measure:

```text
L(A -> B) = minimum bridge complexity achieving a predeclared held-out functional criterion
```

This is the first surviving REE document found in this archaeology that makes **translation complexity itself** an explicit object of study.

It also makes a biologically and architecturally important distinction:

> local specialisation and cross-system legibility can increase together.

That provides a principled alternative to forcing E1, E2, hippocampus, `z_world` and E3 toward one universal representational geometry.

For the hippocampal archaeology, the key bridge is the thought's three-part replay maintenance hypothesis:

- maintain/reorganise the representation;
- maintain the episodic index after representational change;
- maintain or recalibrate the interface through which another subsystem reads it.

The first two are strongly continuous with the older hippocampal architecture. The third is the new explicit translation component.

**Archaeological classification:** explicit modern translation/interface formulation; partially convergent with, but not simply descended from, the February hippocampal line.

## 11. Translation becomes relational to the receiver

### 2026-09-08 — Receiver-conditioned translation and recurrent interface stability

The next child thought changes the abstraction from:

```text
T(sender)
```

toward:

```text
T(sender, receiver, receiver_context)
```

The same sender state may need to expose different information depending on what the receiver already knows, predicts, is evaluating, or has retrieved.

This is a particularly strong convergence with hippocampal retrieval. A remembered episode is not useful merely because its content exists; what matters depends on the **present retrieval query and present consumer state**.

The thought also adds recurrent stability. A bridge that works once can progressively drive a recurrent receiver off-manifold or double-count previously injected evidence.

This again resembles an old hippocampal constraint in a new form: replayed/completed content is a **hypothesis**, not a licence to overwrite perception or commitment.

The surviving genealogy therefore contains a repeated protection against recursive representational contamination:

- early hippocampal architecture: remembered/completed trajectory does not overwrite perceptual state;
- Papez-like provenance: internally generated material requires grounding support;
- receiver-conditioned translation: repeated bridge use must remain on-manifold and avoid semantic double-counting.

**Archaeological classification:** direct child of mutual legibility; independent convergence with older provenance/no-overwrite constraints.

## 12. Shared reference frames and temporal gates complete the present synthesis

### 2026-09-09 — shared reference frames and temporal gates

The current child thought adds two variables that make the old hippocampal lineage suddenly look highly relevant.

A communication subspace answers:

> which sender directions are visible to this receiver?

A shared reference frame answers:

> relative to what are those directions interpreted?

Candidate frames include:

- self-relative direction;
- action candidate;
- trajectory/horizon position;
- temporal order;
- episode identity;
- causal source;
- self/world relation;
- harm/benefit relation.

A temporal gate adds:

> when is the receiver in the phase in which that content can matter?

The current decomposition is therefore:

```text
effective interface =
    content
  x communication subspace
  x reference frame
  x receiver context
  x temporal gate
```

with recurrent stability constraining repeated use.

This is where the early CITM and path-memory work become directly useful again. CITM's action-linked transition tuples and hippocampal episode/trajectory indices are plausible **sources of learned relational coordinates** by which two otherwise different systems could refer to the same event or relation.

The crucial point is that shared reference does not require shared code.

| Migrating causal index | 2026-02-15 backward shift | Early convergence with dynamic re-indexing/temporal relevance |
| Developmental sparsification | June 2026 MECH-362/Q-057 | Independent developmental branch now converging with interface pruning |

The key historical result is therefore **convergent recurrence**, not one continuous single-origin theory.

Multiple strands repeatedly arrive at variants of:

> useful cognition depends on preserving relations across changing representations, contexts, actions and time.

That recurrence makes the synthesis worth testing, but recurrence inside one research programme is not independent empirical evidence.

## 14. The hidden overlap: hippocampal map as translation scaffold

The archaeology suggests a bounded unifying hypothesis.

Let specialised systems A and B have local states `x_A` and `x_B`. Let a hippocampal-like system preserve an index `h_t` that identifies a relational circumstance such as:

- episode;
- action/commitment;
- before/after transition;
- trajectory position;
- self-relative direction;
- causal source;
- temporal phase.

A translation need not be:

```text
x_B = T(x_A)
```

It can instead be a context-bound read surface:

```text
m_(A->B,t) = T_(A->B)(x_A ; h_t, x_B, D_t, p_t)
```

where:

- `h_t` supplies relational/episodic reference;
- `x_B` is receiver state;
- `D_t` is current directive/task/control context;
- `p_t` is temporal phase/gate;
- `m` is a consumer-facing message or temporary projection, not a rewrite of B's whole representation.

The hippocampal contribution in this model is primarily to supply and maintain `h_t`, retrieve matched correspondences, and replay them for learning/recalibration. The bridge `T` can live at the interface or receiver and may be very small once development has organised the relevant correspondence.

This preserves the architectural separation already present in REE:

- hippocampus indexes/replays;
- predictive systems predict;
- E3 selects/commits;
- control machinery gates;
- translation/read surfaces make selected content mutually usable.

There is no need to turn hippocampus into a second executive or universal decoder.

## 15. Developmental prediction

The developmental-overcapacity and CA3-pruning strands suggest a natural history for such mappings:

```text
early:
  many possible correspondences
  broad hippocampal/contextual indexing
  expensive or high-capacity cross-system bridges

learning + action + replay:
  useful pairings recur
  reference frames stabilise
  irrelevant mappings weaken
  bridge complexity falls

mature:
  specialised local representations
  sparse stable relational indices
  low-complexity context-specific interfaces
```

The measurable prediction is not merely that mature systems use fewer parameters. It is:

```text
local competence rises
while
L(A -> B) falls
```

where `L` is the minimum bridge complexity needed for a fixed held-out functional criterion.

A stronger developmental test compares systems that end with the same mature interface architecture but reached it through different developmental histories. If large->pruned development beats the same final sparse architecture trained from the beginning, developmental history itself contributed to finding the mapping.

## 16. What V3-EXQ-1010 can and cannot tell us

1010 is especially useful because it tests a very narrow part of this archaeology.

It freezes the representation and varies decoder capacity over a very large range.

### If a high-capacity decoder succeeds

Then the frozen `z_world` contains a mapping sufficient for action, but that mapping is too difficult for the present native reader.

That result would make the following routes live:

- constrained interface reformatting;
- receiver-conditioned read surfaces;
- reference-frame alignment;
- developmental large->small bridge discovery/distillation;
- replay-assisted interface maintenance.

It would **not** show that the hippocampus must perform the translation.

### If all adequate high-capacity decoders fail to generalise

Then the current frozen `z_world` is unlikely to contain a sufficiently recoverable decision relation for this task.

The translation hypothesis is not falsified globally. The locus moves upstream:

- the encoder objective may need to preserve different relational distinctions;
- developmental overcapacity may need to occur in representation formation rather than the reader;
- replay/rebucketing may need to reorganise the ontology;
- the correct reference frame may need to be present during encoding, not added afterward.

Thus 1010 adjudicates **where** translation/reorganisation would have to operate, not whether all cross-system translation ideas are valid.

## 17. What should not be collapsed into one hypothesis

The archaeology exposes several separable questions that must remain separable experimentally:

1. **Content preservation** — is the relevant relation encoded at all?
2. **External decodability** — can an idealised probe extract it?
3. **Native accessibility** — can the current consumer use it?
4. **Translation complexity** — what minimum bridge class makes it usable?
5. **Reference compatibility** — are sender and receiver indexing the same relation?
6. **Receiver conditioning** — does the useful read surface depend on receiver state?
7. **Temporal gating** — is the interface active at the right phase?
8. **Pair specificity/provenance** — does the correct episode/state pairing matter?
9. **Recurrent stability** — does repeated use remain calibrated/on-manifold?
10. **Developmental learnability** — can the mature low-complexity interface be reached directly, or only through a richer developmental regime?
11. **Causal usefulness** — does changing the interface actually alter downstream computation and behaviour?

Calling all eleven “translation” would obscure rather than clarify the science.

## 18. Archaeological verdict

The internal REE record supports four conclusions.

### A. Translation-like concerns are old in REE

Cross-module type compatibility, relational path indexing and hippocampal handoffs are present in surviving February material. The modern interface problem is therefore not a wholly foreign addition to the architecture.

### B. The explicit translation theory is newer

The strong formulation — specialised systems remaining distinct while communicating through learned, low-complexity, context-sensitive bridges — is a September development. It should not be retroactively attributed to February documents that did not say it.

### C. Hippocampal function is best treated as translation-enabling, not automatically translation-performing

The strongest continuous hippocampal role is:

> **index, bind, retrieve, replay and re-reference relational correspondences across time.**

Those functions can make translation possible between specialised representations without requiring the hippocampus to implement a universal representational code.

### D. The current research programme should test a layered interface, not one giant translator

The most promising synthesis is:

```text
content preserved
-> relationally indexed
-> correct pair/context retrieved
-> consumer-facing transform selected
-> temporally gated
-> causally used
-> recurrently stable
-> developmentally simplified
```

This layered formulation is already rich enough to generate discriminating experiments while remaining compatible with simpler outcomes. A successful linear or low-rank bridge should defeat the need for a more elaborate hippocampal translation story at that boundary. Failure of an over-capacity bridge should move the question upstream rather than invite an even larger translator.

## 19. Next research tranche implied by the archaeology

The archaeology is complete enough to define the next external research campaign without yet changing V3 architecture.

The literature search should now ask narrowly:

1. Do hippocampal-cortical interactions preserve **shared relational/reference variables** despite differing local codes?
2. Does hippocampal replay provide paired examples that alter cross-area readout or representational alignment?
3. Are hippocampal mappings receiver/query/context dependent?
4. Do replay and consolidation reduce the complexity required for downstream readout?
5. Which hippocampal subfields are better understood as pattern-separating/indexing versus reconstructive/relational outputs?
6. Are there developmental data showing broad early mappings becoming sparse structured interfaces, not just local connectivity pruning?
7. Does timing relative to replay/reactivation determine whether cross-system information changes the receiver?
8. What negative evidence argues that hippocampus is *not* necessary for translation between representational systems?

The campaign should explicitly search for counterexamples. The intended outcome is not to prove a hippocampal translator, but to identify which parts of the layered interface have plausible biological analogues and which are uniquely REE engineering hypotheses.

## Minimal summary

The archaeology does not uncover a forgotten REE “translation module.” It uncovers repeated, partly independent solutions to a recurring problem.

The earliest REE hippocampal line treats memory as indexed paths and action-linked transition relations. Later work adds re-indexing, replay-driven representational change, communication subspaces, receiver-conditioned translation, recurrent stability, shared reference frames and temporal gates. The coherent synthesis is that hippocampal-like machinery may help **bind and reinstate the relational coordinates through which specialised representations become mutually legible**, while the actual translation can remain a small, local, receiver-facing interface.

That is a narrower hypothesis than “the hippocampus translates representations,” and it is much easier to falsify.
