# Shared reference frames and temporal gates in cross-system mutual legibility

**Date:** 2026-09-09  
**Status:** child thought / falsifiable interface hypothesis; not a claim registration and not an experiment-queue mutation  
**Parent:** `2026-09-07_mutual_legibility_communication_subspaces.md`  
**Sibling:** `2026-09-08_receiver_conditioned_translation_and_recurrent_interface_stability.md`  
**Implementation companion:** `2026-09-07_mutual_legibility_implementation_assays.md`

## Core thought

The mutual-legibility programme has so far separated representation from access, and access from translation. The newest evidence suggests that this decomposition is still incomplete.

Two specialised systems may be able to communicate not because their full representations are globally similar, and not even because one can be transformed into the other by one fixed bridge, but because both organise some of their activity relative to a **shared reference frame**. In addition, a compatible interface may be useful only when it is opened at the correct **temporal phase** relative to replay, prediction, action, or memory reactivation.

A more complete working abstraction is therefore:

`effective interface = content x communication subspace x reference frame x receiver context x temporal gate`

with recurrent stability constraining repeated use over time.

This does not imply that every REE subsystem should share one ontology or one latent language. It suggests instead that otherwise heterogeneous representations may remain mutually legible when they preserve a common indexing relation: *where*, *when*, *relative to what*, *for which candidate*, *for which episode*, *for which self/world relation*, or another learned relational coordinate.

The corresponding timing hypothesis is equally important:

> **A cross-system mapping can be representationally adequate yet functionally ineffective if the interface is opened at the wrong moment.**

The result is a new distinction between **having a compatible interface** and **engaging that interface at the phase in which its content can actually alter another system**.

---

## 1. Why this is not merely more evidence for communication subspaces

The existing mutual-legibility thought already argues that high-dimensional specialised systems can communicate through lower-dimensional consumer-facing subspaces. The receiver-conditioned child thought further argues that the active read surface may depend on the current receiver state and must remain stable across repeated use.

The new evidence adds two different variables.

### 1.1 Reference frame

A communication subspace says **which directions** of a sender matter to a receiver.

A reference frame says **what relation those directions are indexed against**.

Two systems can use very different local codes while preserving a common relation such as visual-field position, self-relative direction, temporal order, object identity, episode identity, action candidate, causal source, or another relational coordinate.

This makes it possible for the receiver to interpret selected sender content without requiring global representational convergence.

### 1.2 Temporal gate

A bridge or communication subspace says **how content could cross**.

A temporal gate says **when crossing is allowed to matter**.

The same content delivered through the same pathway can plausibly have different effects depending on whether it arrives before, during, or after a prediction update, replay event, sharp-wave ripple, action-selection window, or other internal phase.

Thus mutual legibility is not only spatial/geometric. It may be **phase-structured**.

## 2. Biological evidence for a shared reference frame

### 2.1 Retinotopy as a cross-network scaffold

Steel, Angeli and Robertson, *Retinotopic coding organizes the interaction between internally and externally oriented brain networks*, eLife reviewed preprint v2, revised 2026-09-08. DOI: `10.7554/eLife.110234`.

The study examines the Default Network (DN) and Dorsal Attention Network (dATN), two large-scale systems often described as independent or antagonistic because their coarse activity can oppose one another during internally versus externally oriented cognition.

Using high-resolution 7T functional MRI, individualized network definitions, and voxel-level modelling, the authors report a finer-scale structure that is hidden by global averages. Functional coupling between DN and dATN is organised by **shared visual-field preference**: voxels with matched retinotopic tuning show structured interaction even though the networks remain globally distinct. The authors explicitly describe retinotopic coding as a possible organizing scaffold or common language for interaction between perception- and thought-oriented systems.

The important point for REE is not that retinotopy should be copied. It is the architectural pattern:

> **Globally distinct systems can remain functionally integrated because selected activity in both systems is indexed against the same underlying relational coordinate.**

This is stronger and more specific than simple representational similarity.

### 2.2 What this means conceptually

If two systems both encode information relative to a common reference frame, then their local representational geometries may differ substantially while preserving a relational invariant that allows communication.

For example, system A and system B do not need matching internal coordinates for an object. They may only need to agree on something like:

- the object's position relative to the organism;
- its identity across time;
- its relation to a candidate action;
- its episode/context membership;
- whether it is approaching or receding;
- its causal relation to harm/benefit;
- its temporal order relative to another event.

The reference frame need not be hand-written or symbolic. It can itself be learned.

This creates a possible reconciliation between two REE intuitions that might otherwise pull against each other:

1. specialised subsystems should be free to develop different internal representations;
2. the organism still needs coherent cross-system reference to the same world, self, trajectory, or event.

A shared reference frame can provide coherence without representational collapse.

## 3. Biological evidence for temporal gating

### 3.1 Hippocampal stimulation timed to memory reactivation

Okyere et al., *Hippocampal stimulation timed to memory reactivation shapes human sleep oscillatory dynamics and consolidation*, bioRxiv, posted 2026-09-07. DOI: `10.64898/2026.09.02.748628`.

The study used non-invasive temporal-interference stimulation targeted at the human left hippocampal head during sleep. Stimulation was delivered either **concurrently with induced memory reactivation** or at a mistimed interval before reactivation.

Concurrent stimulation reduced subsequent associative forgetting relative to mistimed stimulation, increased fast-spindle amplitude, and preserved the relationship between slow-oscillation/spindle coupling and memory. The behavioural effect was mediated by distributed spindle/coupling features.

This is not evidence that sleep performs latent-space translation or that a bridge exists between hippocampus and cortex. It is, however, causal evidence that the **timing of hippocampal engagement relative to reactivation changes the functional consequence of that engagement**.

For REE this strengthens a narrower principle:

> **Cross-system influence during offline consolidation can depend on whether the interface is engaged in the correct temporal relation to the replayed content.**

### 3.2 Timing is therefore part of the interface contract

An interface can satisfy all of the following:

- source content is present;
- receiver-facing geometry is adequate;
- the bridge is low-complexity;
- correct paired content matters;
- the receiver remains on-manifold;

and still fail because the information arrives outside the phase in which the downstream system is plastic, receptive, or using that quantity.

This creates an additional category of false negative:

`content present + geometry adequate + wrong temporal gate -> no downstream effect`

Such a result should not automatically be interpreted as evidence that the interface is semantically useless.

## 4. Revised interface decomposition

The current mutual-legibility framework can now be expanded without replacing its earlier ladder.

### 4.1 Representation/use ladder

`encoded -> decodable -> natively accessible -> bridgeable -> pairing-specific -> causally used -> behaviourally useful -> recurrently stable`

### 4.2 Interface-factor decomposition

A separate decomposition asks what must be jointly correct for causal communication to occur:

1. **content** — the sender contains the relevant distinction;
2. **communication subspace** — the distinction overlaps the sender directions visible to the receiver;
3. **reference frame** — sender and receiver organise that distinction relative to a mutually interpretable relational coordinate;
4. **receiver context** — the receiver is in a state where the selected content is relevant and can be interpreted;
5. **temporal gate** — communication occurs during the phase in which the receiver can use or learn from it;
6. **recurrent stability** — repeated use does not drive the coupled system off-manifold or amplify stale information.

The two decompositions answer different questions and should both be retained.

## 5. Candidate REE reference frames

The following are **examples to test for**, not ontologies to hard-code.

### 5.1 Spatial / organism-centred

- self-relative direction;
- distance;
- egocentric versus allocentric location;
- motion/approach relation;
- local affordance direction.

These are immediately relevant to the current directional-resource and waypoint work.

### 5.2 Temporal

- current timestep / relative order;
- recency;
- expected delay to consequence;
- episode phase;
- replay position.

### 5.3 Action-conditioned

- candidate action identity;
- trajectory/horizon index;
- expected consequence relative to candidate action.

This may be especially important for E1/E2 mutual legibility.

### 5.4 Episodic / contextual

- episode identity;
- retrieved context;
- event boundary;
- self-state at encoding versus retrieval.

This is relevant to hippocampal and ContextMemory pathways.

### 5.5 Organismic / ethical

Possible later reference relations might include:

- self versus other;
- source of harm/benefit;
- controllability;
- vulnerability;
- responsibility relation;
- persistence of consequence.

Again, the claim is not that these should be explicit dimensions. The question is whether independently specialised systems preserve some **shared relational indexing** that allows them to refer coherently to the same consequential structure.

## 6. Reference-frame failure versus information loss

The distinction creates a new experimental diagnosis.

Suppose `z_world` contains accurate waypoint direction and E2 contains enough structure to act on direction, but the two encode direction against different frames.

Examples:

- one is allocentric, one egocentric;
- one is current-position-relative, one trajectory-origin-relative;
- one indexes the world at observation time, one at predicted action time;
- one represents absolute location, one action-conditioned displacement.

A probe may succeed on both systems, yet the actual interface fails.

The problem is not missing information. It is **reference-frame incompatibility**.

This suggests that some apparently difficult bridge problems may collapse when the appropriate transformation is framed relationally rather than as arbitrary latent alignment.

## 7. Reference-frame assay

A future diagnostic should compare at least four conditions.

### RF-1 — intact shared frame

Preserve the normal relation between sender content and the candidate reference frame.

### RF-2 — reference-frame permutation

Keep sender states and their gross distribution intact while permuting the frame labels/anchors between episodes or positions.

Examples:

- rotate spatial anchor while preserving latent norm;
- permute episode identity while preserving content statistics;
- swap action-candidate indexing while preserving action-class frequency.

### RF-3 — content permutation with frame preserved

Preserve the frame but break the example-specific content.

### RF-4 — both content and frame destroyed

Negative control.

### Interpretation

- intact >> frame-permuted while content remains decodable -> evidence that shared indexing is functionally important;
- intact ~= frame-permuted -> reference frame may be incidental;
- frame-preserving wrong content performs poorly -> content-specificity remains necessary;
- frame permutation disrupts only one downstream consumer -> reference frames may be consumer-specific rather than globally shared.

The purpose is not to prove a symbolic coordinate system. It is to test whether cross-system use depends on preserving a relational invariant.

## 8. Temporal-gating assay

The sleep result suggests that timing controls should become explicit rather than implicit.

For an otherwise fixed sender/receiver pair, compare the same correctly paired content delivered at:

1. **target phase** — e.g. during the relevant replay/reactivation event;
2. **early-shifted phase**;
3. **late-shifted phase**;
4. **phase-shuffled control** with matched number and amplitude of communications;
5. **no-interface control**.

Where possible preserve total communication energy/updates so that timing, not quantity, is the manipulated variable.

### Candidate measurements

- downstream parameter/state change;
- replay integration;
- post-sleep behavioural retention;
- communication-subspace rotation;
- bridge complexity;
- recurrent stability after wake;
- content-specific causal effect;
- whether the receiving subsystem was in a plastic versus stable mode.

### Critical interpretation

If synchronous communication changes the receiver while temporally displaced communication does not, this is evidence for **phase-specific interface efficacy**, not necessarily for a different representational code.

## 9. Interaction between reference frame and temporal gate

The two new variables may interact.

A replayed event may temporarily instantiate a reference frame that is unavailable during ordinary sleep background activity. For example, hippocampal replay could transiently reconstruct:

- a location anchor;
- an episode index;
- a candidate trajectory;
- a self-state;
- an event boundary.

Only during that window might cortical or E1-like systems be able to interpret transmitted content correctly.

This leads to a stronger REE hypothesis:

> **Offline consolidation may open short-lived, reference-frame-aligned communication windows in which otherwise specialised systems can update one another without requiring persistent global representational alignment.**

This remains a hypothesis. The current biological evidence supports shared reference scaffolds and timing-sensitive consolidation separately; it does not directly demonstrate their conjunction.

## 10. Relation to current REE architecture

### 10.1 `observation -> z_world`

The existing representation contract asks what information survives compression.

The present thought adds:

> Is the information expressed relative to a frame that downstream consumers can interpret?

A directional signal is not fully specified without knowing its coordinate basis.

### 10.2 `z_world -> E1/E2`

E1 and E2 may need different consumer-facing subspaces while still sharing a limited relational reference: action candidate, time horizon, self-relative direction, or predicted consequence relation.

Failure could therefore arise from:

- missing content;
- bad subspace routing;
- coordinate mismatch;
- reference-frame mismatch;
- receiver-context mismatch;
- temporal-gating mismatch.

These should not be collapsed into one `z_world inadequate` diagnosis.

### 10.3 E1 <-> E2

A shared action-conditioned or horizon-conditioned frame may matter more than global latent similarity.

The dynamic-compatibility assay should therefore report whether sender and receiver transitions are being compared in the same action/time frame.

### 10.4 Hippocampus / ContextMemory

Episode identity and retrieval context are natural candidate reference frames.

A retrieved memory can contain the right content but be harmful if indexed to the wrong present context or injected outside the phase in which the consumer expects retrieved evidence.

### 10.5 Sleep/replay

The sleep programme should no longer ask only whether an interface changed before versus after sleep.

It should ask:

- which replay event was active;
- what reference frame that replay instantiated;
- which consumer was receptive;
- at what phase communication occurred;
- which interface changed;
- whether waking recurrent stability improved or worsened.

---

## 11. Failure taxonomy extension

Add two new diagnoses to the mutual-legibility taxonomy.

### RF-F — reference-frame mismatch

Task information exists in sender and receiver and may even be bridgeable under external supervision, but native cross-system use fails because the systems index the content against incompatible relational coordinates.

### TG-F — temporal-gate mismatch

The interface is otherwise adequate, but communication occurs outside the phase in which the receiver can causally use or learn from the transmitted content.

These categories should be considered before concluding that a higher-capacity bridge or new representational mechanism is needed.

---

## 12. Architectural caution

Shared reference frames can easily become a route back to hand-written ontology if treated incautiously.

The default REE position should remain:

- do not prescribe a universal coordinate vocabulary;
- look for relational invariants already emerging in trained systems;
- test whether preserving or scrambling those invariants changes cross-system use;
- prefer low-complexity frame transformations where possible;
- separate a reference frame from the semantic content indexed by that frame;
- allow different interfaces to use different frames;
- do not infer one global workspace/object merely because several consumers share an indexing relation.

Likewise, temporal gating should initially be measured and perturbed diagnostically. Do not add a new gate mechanism unless the existing sleep/wake/control substrate cannot express the required timing.

## Evidence boundary

### Supported by current external evidence

- globally distinct brain networks can show finer-scale coupling organised by a shared retinotopic code;
- timing hippocampal stimulation concurrently versus before induced reactivation can change sleep oscillatory dynamics and memory outcome;
- therefore global representational similarity and gross communication quantity are insufficient descriptions of cross-system coordination.

### Plausible REE extrapolation

- specialised REE subsystems may coordinate through learned shared reference frames without global representational convergence;
- some current nulls may reflect reference-frame mismatch rather than information loss;
- offline interface efficacy may depend on precise timing relative to replay/reactivation;
- shared frame and temporal gate may interact to create transient communication windows.

### Not established

- that REE presently contains such shared reference frames;
- that biological retinotopy is analogous to any specific REE latent coordinate;
- that sleep exists to align interface reference frames;
- that a dedicated new architecture is required;
- that reference-frame alignment necessarily lowers bridge complexity or improves behaviour.

---

## Working principle

> **Mutual legibility may depend not only on what information is present and how it is geometrically exposed, but on whether sender and receiver refer that information to a compatible relational frame and whether the interface is opened at the moment when the receiver can use it. Specialised systems can therefore remain globally different while becoming locally, relationally, and temporally coordinated.**
