## 4. REE-specific hypothesis

REE may need explicit developmental states for capacities:

1. **Latent scaffold** — internal activity creates primitive structure without external use.
2. **Rehearsal** — the capacity is exercised in simulation/offline modes.
3. **Supervised expression** — limited output allowed with low action authority.
4. **Committed use** — the capacity can participate in action, repair, or social coupling.

Possible computational primitive:

```text
capacity_readiness = f(internal_rehearsal, circuit_stability, provenance_control, error_recovery, social_safety, action_authority_gate)
```

This matters because REE should not treat a capacity as safe merely because it can generate output. A capacity may need internal scaffolding and controlled release before it can participate in ethical agency.
