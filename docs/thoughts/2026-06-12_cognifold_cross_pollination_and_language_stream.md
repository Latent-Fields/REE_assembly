Source thought (Daniel, 2026-06-12), preserved verbatim:

> I was considering cognition and how certain parts of AI work. The world model
> predicts a future sensory input and can reap error to get a better world model.
> As long as forming of the world model is supported this process can be an ongoing
> improvement, inferring more detail, accuracy, and precision of the model. The
> affordances model similarly updates but overlaps with the world model in features
> and so combined the modelling is even better. If language is an externalisation of
> internal cognitive processes then language prediction within the cognifold could
> actually instantiate cognitive structures that were poorly inherently gained and
> correct (or potentially worsen) cognitive structures depending on the state of the
> language. Integrating multiple predictive models into a single cognifold is what
> REE is already doing. The cross pollination of models including with object
> relations and the inferences gained must turbo charge development.

## Triage outcome (thought-digestion, 2026-06-12)

Five fragments triaged against the claim registry.

1. **World model reaps error and self-improves (E1).** Already owned by design:
   ARC-001 (E1 persistent predictive substrate) under INV-013 (cognition is
   predictive/iterative/multi-timescale). The "keeps improving while formation is
   supported" property is the definitional behaviour of that pair, not new
   falsifiable ground. Cross-reference only -- not registered (a standalone claim
   would be near-tautological).

2. **Affordances model overlaps E1; combined beats either alone (E2).** Partially
   owned: ARC-002 (E2 affordance predictor), ARC-004 (shared L-space latent),
   MECH-081 (E2 sufficiency constraint shapes E1 dimensionality), MECH-082 (E2
   distortion biases E1 sampling). The interaction + shared substrate are
   registered; the *super-additive benefit* is not. Folded into Fragment 5 as its
   concrete pairwise, V3-testable instance -- it IS the first experiment arm of
   MECH-423, not a separate claim.

3. **Language as an externalised predictive stream (instantiate / correct / worsen).**
   Genuinely new. REE owns language as coordination/compression scaffold (INV-003,
   ARC-009, MECH-010, MECH-011) and a V6 language interface cluster that parses
   affect/grammar *from* language (MECH-373, INV-085, MECH-422). None assert the
   mechanism in this thought: that *predicting language inside the integrated
   substrate* can **instantiate** cognitive structure not gained sensorimotorically,
   and **bidirectionally correct OR degrade** existing structure as a function of the
   language's quality. The bidirectional clause is the discriminating edge.
   Registered as **MECH-424** (substrate_conditional; the linguistic channel it needs
   does not exist until the V6 language layer is built). DO NOT build in V3.

4. **Cognifold (integrating many models into one substrate).** Fully owned:
   ARC-001/002/003 triad, ARC-004 unified latent, ARC-005 control plane, ARC-007 +
   MECH-033 hippocampal integration. "Cognifold" is an unnamed umbrella over existing
   architecture. Cross-reference only.

5. **Cross-pollination turbo-charges development (super-additivity).** Cleanest new
   *testable* ground. Object spine (ARC-080 umbrella + ARC-081/082/083 pillars) and
   transfer mechanisms (MECH-033, MECH-081, MECH-121) exist, but nothing asserts the
   **super-additive / accelerated** claim -- that integration over a shared latent
   yields gains exceeding the sum of isolated models. Registered as **MECH-423**
   (V3-testable ablation, EXP-0380).

## Open readiness question (Daniel, 2026-06-12) -- feeds a lit-pull

The super-additivity signal may be **null until the integration machinery is itself
doing cross-module work** -- a properly running inference loop, DMN-style offline
integration, and sleep consolidation (MECH-121 replay transfer) may all need to be up
and integrated before any super-additive gap appears. Below that, integrated ~= isolated
and the ablation is *degenerate* (substrate_not_ready), not a FAIL. This is baked into
MECH-423's `what_would_answer` as an explicit **readiness precondition**, and motivates a
literature pull on which integration prerequisites (offline replay / DMN-analogue / the
inference loop) are necessary conditions for super-additive cross-model gains. The
lit-pull verdict should set the readiness gate's concrete metric before EXP-0380 is queued.
