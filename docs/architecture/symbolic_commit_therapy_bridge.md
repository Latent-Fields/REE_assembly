# Symbolic Commits and the Therapy Bridge

**Claim Type:** mechanism_hypothesis (MECH-564, MECH-565) + architectural_commitment (ARC-147)
**Scope:** How verbal/symbolic articulation of an affective action-pressure interacts with the commitment machinery (MECH-061 / MECH-090), and why commits must be typed

<a id="mech-564"></a>
## MECH-564 -- Symbolic commit updates arbitration

Verbal or symbolic representation of an undifferentiated affective action-pressure is itself a low-risk *partial* commit: it discharges the pressure into a cheap committed trajectory, and when that symbolic commit produces prediction mismatch (the articulated expectation fails) or social witnessing (another agent responds to it), the mismatch updates future trajectory-arbitration scoring for the affect's full-cost action alternatives. This is the proposed mechanism by which articulating an urge changes what the agent later does. It depends on the commit boundary (MECH-061), its entry predicate (MECH-090), the simulation/real distinction (MECH-094: a symbolic commit must never be booked as enactment), the symbolic route (ARC-009), social coupling (ARC-010) and residue-side correction (MECH-056). Requires a symbolic/language plus social-witnessing substrate.

<a id="mech-565"></a>
## MECH-565 -- Rumination as a mismatchless symbolic loop

Repeated symbolic commits that generate *no* prediction mismatch and *no* social witnessing fail to re-rank the candidate set, so the same trajectory is re-proposed and re-committed symbolically while arbitration never updates. This is a perseveration signature distinct from over-persistence of an *embodied* commitment (MECH-536's post-commit latch), and the discriminator between therapeutic articulation and rumination is whether a symbolic commit changes subsequent arbitration scores. `psychiatric_failure_modes.md` lists rumination three times as a clinical analogue of E3-gate failure; this is the mechanism those rows lack. The source intake flags a possibly V3-tractable proxy (residue plus prediction-mismatch instrumentation on existing commits) -- flagged for `/governance`, not built.

<a id="arc-147"></a>
## ARC-147 -- Commit-type taxonomy

Commits are typed. The commitment machinery must distinguish at least symbolic, embodied, social-witnessed, repair, grief, boundary and rumination commit types, because each carries a different cost, a different mismatch source (or none), a different residue consequence and a different arbitration-update path. A single untyped commit-boundary token (MECH-061) cannot represent that a symbolic partial commit and an embodied full commit of the same trajectory carry different risk and teach different things. The list is open, on the same discipline ARC-095 applies to the affect-stream taxonomy; the repair and grief types are owned conceptually by the V4 ethics cluster (`evidence/planning/thought_intake_2026-05-31_musings_on_v4.md`), cross-linked so the therapy and moral-self threads register together rather than fragment.
