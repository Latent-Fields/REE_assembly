# Monostrategy Etiology Typology

**Status:** candidate claims, registered 2026-09-25 from
`docs/thoughts/2026-09-24_dynamic_coordination_repertoire_monostrategy.md`
(intake: `evidence/planning/thought_intake_2026-09-24_dynamic_coordination_repertoire_monostrategy.md`).
Registration is not build authorisation. **DO NOT build a routing, phase or coordination mechanism in V3
on the strength of this page.**

## Summary

A monostrategic organism may (A) lack useful alternatives, (B) hold them but be unable to give them causal
authority, or (C) hold and route them but be unable to reorganise around them because selective reciprocal
coupling keeps relaxing the joint system back to one coalition. Only B and C can license a coordination
remedy; A calls for generation / representation repair. The typology exists to stop a coordination
mechanism being built to fix what is really a repertoire-absence failure.

<a id="mech-588"></a>
## MECH-588 -- Type A (repertoire absence) vs Type B (access collapse)

Discriminated by a staged chain read at matched decision states -- proposed -> represented -> evaluated ->
committed -> executed -- under generation-side injection of the useful alternative at matched pool size.
Type A is rescued by injection; Type B is not and loses authority at a named later stage. A coordination
remedy is admissible only on a Type-B verdict in an ecology where at least two strategies are each useful,
with a competence gate met, and against matched static-learned-bridge, existing-diversity-pressure,
state-independent random-routing and content-ablation controls that all fail.

Current evidence (2026-09-24/25): the sharpest measured V3 monostrategy (V3-EXQ-1061) is generation-stage
**Type A** -- proposal pool 31:1 and state-invariant
(`evidence/planning/monostrategy_type_a_vs_b_discrimination_20260924.md`, 948d58cd3e4; reproduced at
world_dim 32 in `e2_rollout_divergence_and_proposal_state_dependence_20260924.md`, f300ebf64d6). The Type-A
root is owned by GFLAG-0487 / GFLAG-0488 (untrained compression/readout sites; `action_object_decoder`)
and SD-080. The assay is RED as a whole today, AMBER for Stage 0.

<a id="mech-589"></a>
## MECH-589 -- Type C (consensus over-stabilisation)

Alternatives are represented and routed, and a perturbation can move one subsystem toward them, yet
selective reciprocal coupling relaxes the joint system back to one dominant coalition. Signature: excess
dwell time; contradicting evidence held by one subsystem is extinguished rather than propagated after a
reversal; weakening or correspondence-scrambling the SELECTIVE coupling at matched magnitude releases the
lock-in without degrading local competence. Competes with MECH-080 arm 3 (lock-in inside one subsystem) and
MECH-587 (habit dominance); the coupling cut discriminates. Caution: the self-reinforcing
E1 -> hippocampus -> E2 -> E3 loop shape is NOT diagnostic of Type C -- the measured V3 loop (INV-054 /
GFLAG-0487) is Type A.
